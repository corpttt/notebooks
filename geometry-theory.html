L1. 14.09 — векторные пространства

(из записей Бегалиева; доказательства следствий — из записей + дополнено развёрткой; примеры — из записей)

Аксиомы векторного пространства

Определение. (из записей) Пусть V — множество («векторы»), K — поле (чаще ℝ или ℂ), + : V × V → V, (u, v) ↦ u + v, · : K × V → V, (λ, v) ↦ λv.

Упорядоченная четвёрка (V, K, +, ·) называется векторным пространством, если выполнены аксиомы:

  1. ∀ u, v ∈ V: u + v = v + u (коммутативность сложения);
  2. ∀ u, v, w ∈ V: (u + v) + w = u + (v + w) (ассоциативность);
  3. ∃ 0̃ ∈ V: ∀ u ∈ V: u + 0̃ = u (нулевой вектор; на доске часто пишут просто 0 — не путать со скаляром 0 ∈ K);
  4. ∀ u ∈ V ∃ (−u) ∈ V: u + (−u) = 0̃ (противоположный);
  5. ∀ λ ∈ K ∀ u, v ∈ V: λ(u + v) = λu + λv;
  6. ∀ λ, μ ∈ K ∀ u ∈ V: (λ + μ)u = λu + μu;
  7. ∃ 1 ∈ K: ∀ u ∈ V: 1 · u = u;
  8. ∀ λ, μ ∈ K ∀ u ∈ V: (λμ)u = λ(μu).

Своими словами. Векторы можно складывать между собой и растягивать числами из поля, и эти две операции ведут себя «как привычные стрелки на плоскости»: сложение коммутативно и ассоциативно, есть ноль и «минус вектор», растяжение распределяется по сумме.

Замечание. (из записей) Аксиомы 1–4 — это аксиомы абелевой (коммутативной) группы по сложению.

Пример. V = ℝ², K = ℝ: (x₁, y₁) + (x₂, y₂) = (x₁+x₂, y₁+y₂), λ(x, y) = (λx, λy). Нуль — (0, 0); −(x, y) = (−x, −y). Это «школьные» векторы на плоскости в координатах. (Рис. L-1c — стрелки из начала; L-1a–b — сумма и растяжение.)

Не-пример. Множество точек окружности со «сложением» как обычные векторы из начала координат: сумма двух точек окружности часто не лежит на окружности — замкнутость не выполняется, это не подпространство ℝ².

Полную проверку всех восьми аксиом для каждого примера на лекции часто оставляли упражнением; ниже — следствия и типичные примеры без восьми однотипных проверок подряд.

Следствия аксиом

(формулировки — из записей; ниже — 2 развёрнутых доказательства как образец, остальные — утверждения)

На лекции нулевой вектор обозначали 0̃ (чтобы не путать со скаляром 0).

Утверждение 1. Нулевой вектор единственен: ∃! 0̃ ∈ V.

Доказательство (образец). (из записей, развёрнуто) Пусть 0̃ и 0̃′ — два нуля. Тогда 0̃ = 0̃ + 0̃′ (потому что 0̃′ — ноль) = 0̃′ + 0̃ (коммутативность) = 0̃′ (потому что 0̃ — ноль). Значит 0̃ = 0̃′. ∎

Утверждение 2. Для каждого v ∈ V противоположный −v единственен.

Доказательство (образец). (из записей, развёрнуто) Пусть v + v̄ = 0̃ и v + v̄′ = 0̃. Тогда v̄ = v̄ + 0̃ = v̄ + (v + v̄′) = (v̄ + v) + v̄′ = 0̃ + v̄′ = v̄′. ∎

Утверждение 3. ∀ v ∈ V: 0 · v = 0̃. (доказательство на лекции: 0·v = (0+0)·v = 0·v + 0·v ⇒ после прибавления −(0·v) получаем 0̃ = 0·v.)

Утверждение 4. ∀ α ∈ K: α · 0̃ = 0̃. (упражнение на лекции; идея та же: α·0̃ = α(0̃+0̃) = α·0̃ + α·0̃.)

Утверждение 5. Если α · v = 0̃, то α = 0 или v = 0̃. (из записей: если α ≠ 0, умножаем на α⁻¹ и получаем v = 0̃.)

Утверждение 6. ∀ v ∈ V: (−1) · v = −v. (из записей: (−1)·v + v = (−1+1)·v = 0·v = 0̃ ⇒ (−1)·v — противоположный к v.)

Своими словами. Из аксиом уже следует привычное: «ноль один», «минус один», «ноль раз вектор — ноль», и произведение ноль только если ноль скаляр или ноль вектор.

Пример к следствиям. В ℝ²: 0·(3, −1) = (0, 0); (−1)·(3, −1) = (−3, 1) = −(3, −1).

Примеры векторных пространств

#### (1) ℝⁿ

Определение / конструкция. (из записей) ℝⁿ = {(x₁, …, xₙ) : xᵢ ∈ ℝ}. Сложение и умножение на α ∈ ℝ — покомпонентно. Можно думать про ℝⁿ как про множество отображений {1, …, n} → ℝ.

Своими словами. Столбец из n вещественных чисел; буква n — сколько координат у одного вектора. Складываем и растягиваем «по строчкам».

(Рис. L-1d — схема ℝ¹ / ℝ² / ℝ³; рис. L-1c — как выглядит вектор из ℝ² на плоскости.)

Пример (письменно; 3D не рисуем). В ℝ³ у вектора ровно три числа: (1, 0, 2) + (−1, 4, 0) = (0, 4, 2);   3·(1, 0, 2) = (3, 0, 6). Это та же покомпонентная арифметика, что в ℝ², только координат три.

#### (2) Пространство отображений A → V

Определение. (из записей) Пусть V — векторное пространство над K, A — любое множество. W = {f : f : A → V}. Операции: (f + g)(a) = f(a) + g(a), (λf)(a) = λ f(a).

Своими словами. «Функции со значениями в векторах» складываются так же, как значения в каждой точке.

Пример. A = {утро, вечер}, V = ℝ. Тогда f и g — просто пары чисел (значение утром и вечером); сложение — сложение пар. Это по сути ℝ².

Разжёвка. A и ℝ — разные вещи: A — где смотрим (два слота: утро / вечер), ℝ — какие числа кладём. Одно отображение f задаёт ровно два числа: f(утро) и f(вечер) — как вектор из ℝ². Складывать функции = складывать эти пары покомпонентно.

Не-пример путаницы. «A и значения — два объекта, значит не ℝ²» — нет: вектор как раз и есть набор значений по слотам A. Слотов два ⇒ ℝ².

#### (3) Геометрическое пространство V_Q из евклидова пространства

(из записей) Сами E¹ (прямая), E² (плоскость), E³ (пространство) как множества точек векторными пространствами не являются. Их «достраивают».

Почему точек мало. В векторном пространстве нужно уметь складывать элементы и растягивать скаляром. Для двух точек плоскости «A + B» само по себе не определено: куда указывает сумма? Пока нет стрелок и выбранного начала — одних точек недостаточно. Поэтому ответ на «E² — векторное пространство?» — нет.

Фиксируем точку Q ∈ Eₘ (m = 1, 2, 3). Положим V_Q := {[QX] : X ∈ Eₘ}, где [QX] — направленный отрезок (вектор) из Q в X. Ноль: [QQ]. Сложение — по правилу параллелограмма / треугольника; умножение на скаляр — растяжение/сжатие (и разворот при отрицательном α).

Своими словами. Выбрали «начало» Q и смотрим на все стрелки, начинающиеся в Q. Это уже векторы, а не «голые» точки. «Не соединены» = ещё нет стрелок — тогда векторного пространства нет.

Пример. На плоскости E² возьмём Q — начало координат. Тогда [QX] — обычный радиус-вектор точки X; V_Q выглядит как ℝ².

Коммутативность сложения видна на параллелограмме; ассоциативность на лекции 21.09 поясняли чертежом (на экзамене, по записи, могут не требовать строгого доказательства). (Рис. L-1a — сумма; L-1b — скаляр; L-1c — ℝ².)

Параллельный перенос точки вдоль вектора — биекция плоскости/пространства на себя (из записей, упражнение).

Линейные отображения и изоморфизм

Определение. (из записей) Пусть U, V — векторные пространства над одним полем K. Отображение Φ : U → V линейно, если

  1. Φ(u + v) = Φ(u) + Φ(v) (аддитивность);
  2. Φ(ku) = k Φ(u) (однородность).
Линейность
Φ(u + αv) = Φ(u) + α Φ(v)

Частая путаница. Однородность — это Φ(k u) = k · Φ(u): сначала растянули вектор u на число k, потом применили Φ — то же, что сначала Φ(u), потом растянуть картинку на то же k. Писать «(Φk)u» нельзя: Φ действует на векторы из U, а k — скаляр из поля K, не вектор. Φ к числу k не применяется.

Пример. Φ(x, y) = (2x, 2y), u = (1, 3), k = 4. Слева: Φ(4u) = Φ(4, 12) = (8, 24). Справа: 4·Φ(u) = 4·(2, 6) = (8, 24). Совпало. «(Φ·4)·u» смысла не имеет: 4 не лежит в ℝ².

Изоморфизм — биективное линейное отображение U → V. (из записей) Если Φ — изоморфизм, то Φ⁻¹ тоже изоморфизм (упражнение на лекции; идея: биекция очевидна наличием обратного; линейность обратного проверяют, применяя Φ к нужным равенствам).

Своими словами. Линейное отображение «уважает» сложение и растяжение: картинка суммы = сумма картинок. Изоморфизм — «это по сути одно и то же пространство, только назвали элементы иначе».

Пример. Φ : ℝ² → ℝ², Φ(x, y) = (2x, 2y) — линейно (растяжение в 2 раза), биективно ⇒ изоморфизм. Не-пример. Ψ(x, y) = (x², y) — не линейно: Ψ((1,0)+(1,0)) = Ψ(2,0) = (4, 0), а Ψ(1,0)+Ψ(1,0) = (1,0)+(1,0) = (2, 0).

Пример из геометрии. (из записей, идея) Пространства V_{Q₁} и V_{Q₂} в одном евклидовом пространстве изоморфны: вектор [Q₁X] переносится параллельно так, чтобы начало стало в Q₂. Обратное — перенос обратно. Это как раз «смена начала отсчёта не меняет геометрию векторов».

L2. 21.09 — аффинные пространства

(из записей Бегалиева; пояснения и примеры — дополнено)

Аксиомы аффинного пространства

Определение. (из записей) Тройка (A, V, ·), где A — множество точек, V — векторное пространство, а отображение A × A → V сопоставляет паре точек (X, Y) вектор XY ∈ V, называется аффинным пространством с ассоциированным V, если:

Аксиомы аффинного пространства
1) ∀ X ∈ A ∀ v ∈ V ∃! Y ∈ A: XY = v
2) ∀ X, Y, Z ∈ A: XY + YZ = XZ

(1) из любой точки можно единственным образом «отложить» любой вектор; (2) правило треугольника / замыкание ломаной.

Своими словами. Точки сами по себе не складываются. Но между двумя точками есть вектор «куда идти». Аксиома 1 говорит: «стоя в X и имея вектор v, ровно одна точка Y в конце стрелки». Аксиома 2: путь X→Y→Z даёт тот же суммарный вектор, что X→Z напрямую. (Рис. L-2a–b; свободные векторы — L-2c.)

Не путать. Складывать можно векторы из V (элементы XY, YZ, …). Запись «X + Y» для двух точек из A не определена: точки — не векторы. Связь точек с векторами — через «стрелку» XY или через «отложить v из X» (аксиома 1), а не через сумму точек.

Не-пример. На плоскости взять точки O и A. Имеет смысл OA (вектор) и O + OA в смысле «отложить OA из O → точка A». Не имеет смысла «O + A» как сумма двух точек.

Пример. Обычная плоскость: A = E², V = «свободные векторы плоскости», XY — направленный отрезок от X к Y (как класс / как элемент V). Это интуиция, к которой лекция идёт через фактор (ниже).

Следствия XX = 0 и −XY = YX

Следствия
XX = 0̃  −XY = YX

Утверждение. (из записей) ∀ X ∈ A: XX = 0̃.

Доказательство. (из записей, развёрнуто) По аксиоме 1 для вектора v и точки X есть единственная Y с XY = v. В частности, для v = XX существует единственная точка — это X сам. С другой стороны, XX + XX = XX (аксиома 2 при Y = Z = X). Но тогда XX + XX = XX = XX + 0̃ ⇒ (прибавив −XX) XX = 0̃. Иначе (короче, как в записи): для любого v = XY имеем v + XX = XY + XX = XY = v ⇒ XX действует как ноль ⇒ XX = 0̃. ∎

Утверждение. (из записей) ∀ X, Y ∈ A: −XY = YX.

Доказательство. XY + YX = XX = 0̃ ⇒ YX — противоположный к XY. ∎

Своими словами. «Стрелка из точки в себя — ноль». «Обратный путь — минус вектор».

Пример. На числовой прямой A = ℝ как аффинное пространство над V = ℝ: XY := Y − X. Тогда XX = 0, −(Y−X) = X−Y = YX. Подходит.

Примеры аффинных пространств

Пример 1. (из записей) Само векторное пространство как аффинное: (A, V) = (V, V), и для X, Y ∈ V полагаем XY := Y − X. Проверка аксиом сводится к свойствам вычитания в V.

Пример 2. (из записей) Евклидовы Eₙ (n = 0…3) с векторами, построенными из направленных отрезков (см. следующий блок).

Отношение эквивалентности и фактор

Зачем этот кусок на геометрии: свободный вектор — это класс равных (параллельно перенесённых) направленных отрезков.

Определение. (из записей) Бинарное отношение R ⊆ M × M: пишем x R y, если (x, y) ∈ R.

Свойства:

  1. рефлексивность: ∀ a: a R a;
  2. симметричность: a R b ⇒ b R a;
  3. транзитивность: a R b и b R c ⇒ a R c.

Определение. Отношение эквивалентности ∼ — то, у которого есть все три свойства. Класс [x]_R := {y ∈ M : x R y}.

Свойства классов (из записей):

  • классы либо совпадают, либо не пересекаются;
  • объединение всех классов = M

⇒ классы образуют разбиение M. Множество классов — фактор-множество M / R.

Своими словами. Эквивалентность — «считаем некоторых разными объектами одинаковыми». Класс — «все, кого мы склеили вместе». Фактор — «новое множество, элементами которого являются эти кучки».

Пример. На ℤ: a ∼ b ⟺ a − b чётно. Классы: «чётные» и «нечётные». Фактор — два элемента. Не-пример. Отношение a R b ⟺ a < b на ℝ: не рефлексивно (a ≮ a) — не эквивалентность.

Диагональ D = {(x, x) : x ∈ M} — отношение равенности «каждый только сам с собой»; фактор M/D биективен самому M (из записей, без подробного доказательства).

Направленные отрезки → свободные векторы

(из записей Бегалиева; идея конструкции)

В Eₙ рассматривают направленный отрезок [XY⟩. Антоник задаёт его парой (X, [XY]), где X — начало, [XY] — «прокладываемый» отрезок/вектор из начала: зная начало и вектор, знаем направление и конец.

M — множество всех направленных отрезков в Eₙ.

Отношение ∼ на M: [XY⟩ ∼ [WZ⟩, если [WZ] получается из [XY] параллельным переносом, переводящим X в W (длина и направление сохраняются).

Класс [[XY⟩]_∼ обозначают как свободный вектор XY (начало больше не важно — важны длина и направление).

V = { XY : X, Y ∈ Eₙ } — множество таких классов. Можно зафиксировать начало (удобно «нулевое») и отождествить классы с векторами вида [QX] из конструкции V_Q лекции 14.09.

Своими словами. Много стрелок на плоскости «одинаковой длины и направления, но из разных точек» — это один свободный вектор. Операции на классах задают через представителя: сложили/растянули отрезки с общим началом — получили новый класс. Линейность операций «очевидна раскрытием» (формулировка из записей). Тогда (Eₙ, V, (X,Y) ↦ XY) — аффинное пространство.

Пример. Стрелка из (0,0) в (2,1) и стрелка из (3,3) в (5,4) — один и тот же свободный вектор (2, 1): вторая получается переносом первой на (3, 3).

Дальше на курсе эту конструкцию используют как мост: «геометрические стрелки» ↔ «элементы абстрактного V». Продолжение и доказательства — лекция L3 (28.09).

L3. 28.09 — свободные векторы, ЛНЗ, базис Гамеля

(Из записей Бегалиева: Геометрия 28.09.2026.pdf; локально материалы/_архив/_бегалиев-геометрия/28.pdf. Фото доски: материалы/_архив/доска-28.09-аффинные/. Своими словами, примеры и промежуточные шаги — дополнено.)

Видео: МГУ, Тимашёв — векторные пространства: ЛНЗ и базис.

Связь с прошлым. L2 ввела аффинное пространство и классы направленных отрезков (свободные векторы). На 28.09 доводят: операции на классах корректны, V — векторное пространство, (Eₙ, V) — аффинное; затем переходят к линейной комбинации, ЛНЗ, базису (в т.ч. базису Гамеля) и к следствию про аддитивные неоднородные функции.

Операции на V и корректность

Напоминание (из записей, блок «информация с прошлой лекции»). Направленный отрезок [XY⟩ = (X, [XY]) в Eₙ, n ∈ {0, …, 3}. M = {[XY⟩ : X, Y ∈ Eₙ}. [XY⟩ ∼ [WZ⟩, если [WZ] получается параллельным переносом [XY], переводящим X в W. Свободный вектор XY := [[XY⟩]_∼. V = { XY : X, Y ∈ Eₙ }. Зафиксировав начало (удобно «нулевое»), можно отождествить классы с отрезками из одной точки: { XY : Y ∈ Eₙ }.

Определение операций на V (из записей). Берут представителей с общим началом X:

  • u + v: если u = XY, v = XZ′, то u + v := [[(X, [XY] + [XZ′])⟩]_∼;
  • λ · u: λ · XY := [[(X, λ · [XY])⟩]_∼.

То есть операции «переносят» со структуры привязанных отрезков Vₙ = {[XY] : Y ∈ Eₙ} (уже векторное пространство с лекции 14.09).

Своими словами. Чтобы сложить два свободных вектора, рисуешь оба из одной точки, складываешь стрелки как обычно, и смотришь на класс результата. Растяжение — то же.

Пример. Из точки O: u = (2, 0), v = (0, 3). Сумма — класс стрелки (2, 3). Из другой точки A(1, 1) те же направления дают концы (3, 1) и (1, 4); сумма снова класс (2, 3). (Рис. L-3a.)

Проверка корректности (из записей + доска). Нужно: если [X₁Y₁⟩ ∼ [XY⟩ и [W₁Z₁⟩ ∼ [WZ⟩, то

[[(X, [XY] + λ[WZ])⟩]_∼ = [[(X₁, [X₁Y₁] + λ[W₁Z₁])⟩]_∼.

Параллельный перенос Φ_X^{X₁} — изоморфизм (с лекции 14.09):

Φ_X^{X₁}([XY] + λ[XZ′]) = Φ_X^{X₁}([XY]) + λ Φ_X^{X₁}([XZ′]) = [X₁Y₁] + λ[X₁Z₁′].

Параллелограмм XYPZ″ переносится в X₁Y₁P₁Z₁″ ⇒ [XP⟩ ∼ [X₁P₁⟩. Коммутативность сложения и аксиомы векторного пространства для V проверяются так же, как для привязанных отрезков (из записей: «очевидна / как для Vₙ»).

Своими словами. Можно целиком «перетащить» чертёж в другую точку — класс суммы/растяжения не изменится. Значит операции на классах не зависят от выбора начала. Тогда V — векторное пространство, а (X, Y) ↦ XY задаёт структуру аффинного пространства на Eₙ.

Не-пример корректности (что было бы плохо). Если бы сумма зависела от точки начала (например, «всегда брать конец первого вектора как начало второго» без параллельного переноса), классы смешались бы — свободный вектор перестал бы быть «свободен».

Изоморфизм Ψ : V → Vₙ

Определение. (из записей) Ψ : V → Vₙ,

Ψ([[WZ⟩]_∼) = [XZ′], где [WZ⟩ ∼ [XZ′]

(каждый класс отображаем в привязанный отрезок-представитель с выбранным началом X).

Обратное: Ψ⁻¹([XY]) = [[XY⟩]_∼. Значит Ψ — биекция. Линейность следует из того, что параллельный перенос — изоморфизм, поэтому Ψ — изоморфизм V ≅ Vₙ.

Своими словами. «Свободные» и «привязанные к одной точке» — одна и та же линейная алгебра, только с разной картинкой. На доске те же стрелки обозначали ψ_X : V → V_X.

Пример. В плоскости: класс всех стрелок длины 1 вправо ↔ конкретная стрелка из O в (1, 0). Сложение классов ↔ сложение координат привязанных стрелок.

Линейная комбинация и ЛНЗ

Дальше V — любое векторное пространство над полем K (из записей).

Определение. Пусть u₁, …, uₙ ∈ V, λ₁, …, λₙ ∈ K. Сумма

λ₁ u₁ + … + λₙ uₙ = ∑_{i=1}^n λᵢ uᵢ

называется линейной комбинацией векторов u₁, …, uₙ с коэффициентами λ₁, …, λₙ. Если хотя бы один λᵢ ≠ 0, комбинация нетривиальная.

Своими словами. Берёшь несколько векторов, каждый растягиваешь своим числом и складываешь.

Пример. В ℝ²: 2·(1, 0) + (−1)·(0, 1) = (2, −1). Коэффициенты 2 и −1 — не все нули ⇒ нетривиальная. (Образ базиса и комбинации — рис. L-3b; коэффициенты — числа, не «третья координата».)

Не-пример (письменно). 0·(1, 0) + 0·(0, 1) = (0, 0) — тривиальная комбинация (все коэффициенты нули). Она всегда даёт ноль и ни о чём не говорит.

Определение. Подмножество U ⊂ V линейно независимо (ЛНЗ), если для любых u₁, …, uₙ ∈ U и любых λ₁, …, λₙ ∈ K

∑ λᵢ uᵢ = 0 ⇒ ∀ i λᵢ = 0.

То есть нет нетривиальной линейной комбинации, равной нулю.

Своими словами. Векторы «не дублируют» друг друга: ни один нельзя собрать из остальных. Если сумма с коэффициентами дала ноль — значит, все коэффициенты были нулями.

Пример. В ℝ² векторы e₁ = (1, 0), e₂ = (0, 1) — ЛНЗ: λ₁ e₁ + λ₂ e₂ = (λ₁, λ₂) = 0 ⇒ λ₁ = λ₂ = 0. (Рис. L-3b — они не на одной прямой.)

Не-пример. (1, 0) и (2, 0): второй = 2·первый. 2·(1, 0) + (−1)·(2, 0) = 0 — нетривиальная зависимость. (Рис. L-3c.) Тот же тип зависимости: (1, 0), (2, 0), (0, 1) тоже не ЛНЗ.

Порождающий набор и базис

Определение. W ⊂ V — порождающий набор, если ∀ v ∈ V существуют n ∈ ℕ, векторы u₁, …, uₙ ∈ W и скаляры λ₁, …, λₙ ∈ K такие, что

v = ∑ λᵢ uᵢ.

Своими словами. Из «кирпичей» W можно сложить любой вектор пространства.

Пример. {(1, 0), (0, 1), (1, 1)} порождает ℝ² (уже первых двух хватает). Не-пример. {(1, 0)} не порождает ℝ²: вектор (0, 1) из одного горизонтального не собрать.

Определение. Порождающий набор W ⊂ V называется базисом, если представление любого v через элементы W единственно:

∀ v ∈ V ∃! n ∈ ℕ, ∃! u₁, …, uₙ ∈ W, ∃! λ₁, …, λₙ ∈ K: v = ∑ λᵢ uᵢ.

Своими словами. Базис — «ровно нужный набор осей»: хватает породить всё, и координаты при этом однозначны.

Пример. Стандартный базис ℝ²: {(1, 0), (0, 1)}. У (3, −2) ровно одно разложение: 3·(1, 0) + (−2)·(0, 1). (Рис. L-3b.)

Теорема (базис Гамеля). (из записей) В любом векторном пространстве существует базис (базис Гамеля). Без доказательства на лекции; идея доказательства опирается на лемму Цорна (помечено в записях).

Дополнено (осторожность). Базис Гамеля для ℝ как пространства над ℚ — «дикий» объект: его нельзя явно выписать, существование неконструктивно. Для курса важно само утверждение «базис есть» и следствия ниже; дальше обычно работают с конечномерными пространствами.

Конечномерность и dim V

Определение. (из записей) V конечномерно, если у него есть базис конечной мощности. Дальше на курсе рассматривают в основном такие.

Предложение №1. (из записей) Если W и W′ — базисы V, то |W′| = |W|. Это общее число обозначают dim V (размерность).

Своими словами. Сколько «осей» ни выбирай в качестве базиса — их всегда одинаково много. Это число и есть размерность.

Пример. dim ℝⁿ = n. dim {0} = 0 (базис — пустой набор).

Предложение №2. (из записей; равносильность — упражнение на лекции) Для W ⊂ V равносильны:

  1. W — базис;
  2. W — максимальный ЛНЗ набор в V (нельзя добавить вектор, не потеряв ЛНЗ);
  3. W — минимальный порождающий набор (нельзя выкинуть вектор, не потеряв порождение);
  4. W — ЛНЗ и порождающий одновременно.

Пример к (2)/(3). В ℝ² набор {(1, 0)} ЛНЗ, но не максимален: можно добавить (0, 1). Набор {(1, 0), (0, 1), (1, 1)} порождает, но не минимален: (1, 1) лишний.

Аддитивные, но не однородные функции

Зачем это на лекции. (из записей) Из существования базиса в любом пространстве следует, что бывают функции f с

f(a + b) = f(a) + f(b),

но не обязательно f(λ a) = λ f(a) для всех скаляров λ. То есть аддитивность ≠ линейность.

Шаг 1. Из аддитивности следует ℚ-однородность. (из записей) Для n ∈ ℕ: f(n x) = f(x + … + x) = n f(x). Отсюда f(x) = f(n · (x/n)) = n f(x/n) ⇒ f(x/n) = (1/n) f(x). При x = y = 0: f(0) = f(0) + f(0) ⇒ f(0) = 0. При y = −x: f(0) = f(x) + f(−x) ⇒ f(−x) = −f(x). Собирая: ∀ a ∈ ℚ, ∀ x f(a x) = a f(x).

Своими словами. Если функция только «уважает сложение», для рациональных множителей однородность всё равно вылезает сама. Беда начинается на иррациональных коэффициентах.

Шаг 2. Контрпример через базис Гамеля. (из записей; поле уточнено) Рассматриваем ℝ как векторное пространство над ℚ (в записях местами написано «над ℝ» — для конструкции Гамеля нужен именно ℚ: иначе базис одномерен и трюк не работает). Пусть W ⊂ ℝ — базис Гамеля над ℚ. Зафиксируем w ∈ W и зададим f на базисе:

f(u) = 1, если u = w;  f(u) = 0, если u ∈ W, u ≠ w;

и продолжим по линейности над ℚ: для r = ∑ λᵢ uᵢ (единственное конечное разложение) полагаем f(r) = ∑ λᵢ f(uᵢ). Тогда f(r) равно коэффициенту при w в разложении r.

Возьмём w′ ∈ W, w′ ≠ w. Тогда f(w′) = 0, но λ := w′/w ∈ ℝ \\ ℚ в общем положении, и

f(λ w) = f(w′) = 0,  λ f(w) = λ · 1 = λ ≠ 0,

значит f(λ w) ≠ λ f(w). При этом f аддитивна по построению.

Пример-картинка (не доказательство). Обычная f(x) = 3x и аддитивна, и однородна над ℝ. «Дикая» f из базиса Гамеля аддитивна, на рациональных ведёт себя прилично, а на каких-то иррациональных «ломает» однородность — но явно её не нарисуешь.

Не-пример. f(x) = x² не аддитивна: f(1+1) = 4 ≠ 1+1 = f(1)+f(1). Это другой тип «плохой» функции.

L4. 05.10 — размерность, базисы в Eₙ, аффинные комбинации

(Из записей Бегалиева: Геометрия 10.05.2026.pdf; локально материалы/_архив/_бегалиев-геометрия/05.pdf. Фото доски: 05.10-лекция.pdf. Своими словами, примеры и рисунки — дополнено.)

Видео: МГУ, Мануйлов — линейная алгебра / teach-in.

Связь с прошлым. L3 ввела линейную комбинацию, ЛНЗ, базис и объявила предложение «все базисы одной мощности = dim V». На 05.10 это доказывают (замена по Штейницу / индукция), разбирают, как выглядят базисы в V⁰…V³, и переходят к аффинным комбинациям (сумма коэффициентов = 1) — мост к барицентрическим координатам и центру масс на L5.

Доказательство инвариантности dim

Предложение. (из записей / доска) Если W и W′ — базисы конечномерного векторного пространства V, то |W| = |W′|. Это общее число и есть dim V.

Своими словами. Сколько бы «систем осей» ни выбирали — в каждой ровно одинаковое число векторов. Иначе «размерность» зависела бы от каприза выбора базиса.

Идея доказательства (замена / индукция). Пусть u₁, …, uₙ — базис, а w₁, w₂, … — элементы другого базиса (его мощность ≥ n; иначе сразу |W′| < n и противоречие с симметричным рассуждением). Индукцией по n показывают: первые n векторов второго базиса тоже образуют базис. Тогда второй базис не может быть длиннее n — иначе wₙ₊₁ разлагался бы по первым n, и набор перестал бы быть ЛНЗ.

Шаг замены (лемма типа Штейница). Пусть {u₁, …, uₙ} — базис, w₁ ≠ 0. Разложим

w₁ = ∑_{i=1}^n λᵢ uᵢ.

Так как w₁ ≠ 0, найдётся индекс i₁ с λ_{i₁} ≠ 0. Тогда u_{i₁} выражается через w₁ и остальные uᵢ:

u_{i₁} = (1/λ_{i₁}) ( w₁ − ∑_{i≠i₁} λᵢ uᵢ ).

Подставляя это в произвольное разложение v = ∑ μᵢ uᵢ, получают

Формула
v = ∑_{i≠i₁} (μᵢ − (μ_{i₁}/λ_{i₁}) λᵢ) uᵢ + (μ_{i₁}/λ_{i₁}) w₁

То есть набор {uᵢ : i ≠ i₁} ∪ {w₁} порождает V. Единственность (из записей Бегалиева, развёртка Антоника): приравнивают два разложения, подставляют w₁ = ∑ λᵢ uᵢ, собирают коэффициенты при ЛНЗ-наборе {uᵢ}; из λ_{i₁} ≠ 0 следует ν_{i₁} = μ_{i₁}/λ_{i₁} и для i ≠ i₁ — νᵢ = μᵢ − λᵢ ν_{i₁}. Значит новый набор — снова базис: один u заменили на w.

Своими словами. Новый вектор «съедает» место одного старого: выкидываешь ту ось, на которую у нового вектора ненулевая координата, и вставляешь новый. После n таких замен весь базис состоит только из w₁, …, wₙ.

Пример (письменно, ℝ²). Базис e₁ = (1, 0), e₂ = (0, 1). Возьмём w₁ = (1, 1) = 1·e₁ + 1·e₂. Можно заменить, скажем, e₁: тогда новый базис {(1, 1), (0, 1)}. Любой (a, b) = a·(1, 1) + (b−a)·(0, 1) — единственно. Если бы пытались добавить ещё w₂ без выкидывания — три вектора в ℝ² неизбежно ЛЗ.

Не-пример. Набор {(1, 0), (2, 0)} не базис: замену «по Штейницу» начинать не с чего осмысленного для порождения плоскости — оба вектора на одной прямой, dim span = 1 ≠ 2.

Базисы в V⁰…V³

Для аффинных пространств Eₙ (n = 0, 1, 2, 3) ассоциированное пространство свободных векторов обозначают Vₙ (или Vⁿ). Геометрический смысл базиса — «сколько независимых направлений».

V⁰ (точка). Единственная точка; свободных направлений нет. Базис — пустой набор. dim V⁰ = 0.

Своими словами. Некуда «идти» стрелкой: пространство векторов — только ноль.

Пример. E⁰ = {P}. Вектор PP = 0̃ — единственный. Базис ∅.

V¹ (прямая). Базис — любой ненулевой вектор на прямой. dim V¹ = 1.

Своими словами. Одно направление (вперёд/назад — это скаляр ±). Все ненулевые стрелки на прямой — растяжения друг друга.

Пример. На прямой точки A ≠ B: набор {AB} — базис. Любой XY = λ · AB для единственного λ ∈ ℝ. (Рис. L-4a.)

Не-пример. {AA} = {0̃} не базис: ноль не порождает ненулевые векторы и не ЛНЗ в смысле «максимального» набора направлений.

V² (плоскость). (из записей)

Формула
{AB, CD} — базис V² ⟺ AB ∦ CD
(A ≠ B, C ≠ D; прямые (AB) и (CD) пересекаются / направления независимы)

Тогда dim V² = 2. Любой вектор плоскости — единственная комбинация λu + μv. (Рис. L-4b.)

Своими словами. Две оси не на одной прямой: ими можно накрыть всю плоскость параллелограммом.

Пример. u = (1, 0), v = (0, 1) — базис. Вектор (3, −2) = 3u + (−2)v.

Не-пример. (1, 0) и (2, 0) параллельны — не базис плоскости.

V³ (пространство). Базис — три некомпланарных (не лежащих в одной плоскости) вектора u, v, w. dim V³ = 3.

Своими словами. Три ребра «ящика» из одной вершины: ими собирают любой пространственный вектор как диагональ параллелепипеда.

Пример. z = λu + μv + νw — единственно при ЛНЗ {u, v, w}: если два разложения, разность даёт (λ−λ′)u + … = 0 ⇒ все разности нули. (Рис. L-4c.)

Не-пример. Три вектора в одной плоскости (даже если попарно непараллельны) — ЛЗ в V³, не базис пространства.

Аффинные комбинации и барицентрические координаты

(из записей Бегалиева) Слово barys (др.-греч.) — «тяжесть / сила»: барицентрические координаты — веса в физической картинке центра масс (подробнее на L5).

Определение. (из записей) Пусть X₁, …, Xₘ — точки аффинного пространства A, а λ₁, …, λₘ ∈ ℝ таковы, что

Формула
∑_{i=1}^m λᵢ = 1

Тогда точка

X = ∑_{i=1}^m λᵢ Xᵢ

называется аффинной комбинацией точек Xᵢ (коэффициенты λᵢ — барицентрические координаты X относительно этого набора, когда они определены однозначно).

Своими словами. Обычная линейная комбинация векторов разрешает любые коэффициенты. Для точек сумма коэффициентов должна быть ровно 1 — иначе результат зависел бы от выбора «начала отсчёта».

Независимость от начала. (доска) Фиксируем произвольные начала O и Q. Пишем ∑ λᵢ OXᵢ как вектор из O и ∑ λᵢ QXᵢ как вектор из Q. При ∑ λᵢ = 1:

OQ + ∑ λᵢ QXᵢ = ∑ λᵢ (OQ + QXᵢ) = ∑ λᵢ OXᵢ,

то есть оба способа указывают на одну и ту же точку X. Без условия ∑ λᵢ = 1 равенство ломается.

Пример. Середина отрезка XY: M = (1/2)X + (1/2)Y. Сумма коэффициентов 1. Из любой точки O: OM = (OX + OY)/2.

Не-пример. «(1/2)X + (1/3)Y» — сумма ≠ 1; такая запись для точек некорректна (зависит от начала).

Формула деления отрезка. (из записей) Точка Z на прямой (XY), λ + μ = 1, Z = λ X + μ Y. Тогда XZ = μ · XY, YZ = −λ · XY, откуда

Формула
Z = (ZY / XY) · X + (XZ / XY) · Y
μ = XZ/XY, λ = ZY/XY — коэффициенты разложения по базису {XY} в V¹

(отношения направленных отрезков на прямой). Эквивалентно Z = λ X + (1−λ) Y.

Своими словами. Чем ближе Z к X, тем больше «вес» у X (коэффициент при X = ZY/XY). На прямой это ровно координата вектора XZ (или ZY) в одномерном базисе {XY}.

Знаки на прямой. Для Z = λ X + μ Y, λ + μ = 1: (рис. L-4d)

  • левее X: μ < 0, λ > 1;
  • на отрезке [XY]: 0 ≤ λ, μ ≤ 1;
  • правее Y: λ < 0, μ > 1;
  • в самой X: μ = 0, λ = 1; в Y: λ = 0, μ = 1.

Пример. X = 0, Y = 10 на числовой прямой, Z = 4. Тогда XZ = 4, ZY = 6, XY = 10 ⇒ Z = (6/10)·0 + (4/10)·10 = 4. Коэффициенты 0,6 и 0,4 оба в [0, 1].

Что взять с собой

  • Все базисы одной мощности → dim V; доказательство — замена (Штейниц) + индукция.
  • V⁰: ∅; V¹: ненулевой; V²: непараллельные; V³: некомпланарные.
  • Аффинная комбинация: ∑ λᵢ = 1; иначе зависит от начала.
  • Деление отрезка: Z = (ZY/XY)X + (XZ/XY)Y; знаки λ, μ на прямой.

L5. 12.10 — центр масс, сужение, линейные и аффинные подпространства

(Из фото доски / локального PDF: 12.10-лекция.pdf. В Release Бегалиева на момент разбора не было PDF за 12.10.2026. OCR/кадры: материалы/_архив/_geom-ocr-2026-10/. Своими словами и примеры — дополнено.)

Видео: МГУ, Тимашёв — подпространства / teach-in.

Связь с прошлым. L4 дала аффинные комбинации и деление отрезка. На 12.10 то же читают как центр масс, смотрят знаки барицентрических координат в треугольнике, вводят сужение отображений и §4: линейные / аффинные подпространства, lin и aff.

Центр масс / рычаг

Две точки. Массы m₁ в X и m₂ в Y (mᵢ > 0). Центр масс Z — точка опоры рычага в равновесии:

Формула
Z = (m₁/(m₁+m₂)) X + (m₂/(m₁+m₂)) Y
XZ / ZY = m₂ / m₁

Это та же формула деления: коэффициент при X равен ZY/XY = m₁/(m₁+m₂). (Рис. L-5a.)

Своими словами. Тяжёлая гиря «перетягивает» опору к себе: больше масса у X — Z ближе к X.

Пример. m₁ = 2 в X, m₂ = 1 в Y. Тогда Z = (2/3)X + (1/3)Y, XZ:ZY = 1:2.

Система k точек. Массы m₁, …, mₖ в точках X₁, …, Xₖ, M = ∑ mᵢ > 0. Центр масс

Формула
Z = ∑_{i=1}^k (mᵢ / M) Xᵢ  (∑ (mᵢ/M) = 1)

Своими словами. Обычное взвешенное среднее точек; веса автоматически дают аффинную комбинацию.

Пример. Три равные массы в вершинах треугольника → Z — пересечение медиан (барицентр).

Знаки барицентрических координат в треугольнике (E²)

Для точки P = αA + βB + γC с α+β+γ = 1 в плоскости треугольника ABC плоскость делится на 7 областей знаками (α, β, γ): внутри все > 0; в трёх «бесконечных» углах при вершинах один > 1 и два < 0; в трёх полосах напротив сторон один < 0 и два > 0. (Рис. L-5b.)

Своими словами. Внутри треугольника все «веса» положительны. За стороной BC (напротив A) вес α отрицателен — как «левее X» на прямой.

Пример. Барицентр G = (1/3)A + (1/3)B + (1/3)C — все знаки «+», внутри.

Не-пример. Точка на продолжении медианы за сторону BC имеет отрицательную координату при A.

Сужение отображений F|_{A'}^{B'}

Определение. (из записей) Пусть F : A → B (например, аффинное отображение), A′ ⊂ A, и B′ ⊂ B таково, что F(A′) ⊂ B′. Сужение

Формула
F|_{A'}^{B'} : A′ → B′, x ↦ F(x)

Если B′ = B, пишут коротко F|_{A′} — «сужение F на A′ ⊂ A».

Своими словами. Та же формула F, но домен и/или кодомен уже поменьше. Полезно, когда образ лежит в подпространстве.

Пример. F : ℝ² → ℝ², F(x, y) = (x, 0) (проекция на ось). A′ = ось Oy, F(A′) = {0}. Тогда F|_{A′}^{{0}} — постоянное отображение в ноль.

Не-пример. Нельзя писать F|_{A′}^{B′}, если какой-то F(x) при x ∈ A′ не лежит в B′.

§4. Линейные и аффинные подпространства

Определение (линейное подпространство). (из записей) U ⊂ V — линейное подпространство, если U само является векторным пространством относительно тех же операций + и ·. Эквивалентный критерий:

Формула
∀ u, v ∈ U, ∀ λ ∈ K: u + λ v ∈ U

Своими словами. Из «своих» векторов нельзя выскочить наружу ни суммой, ни растяжением.

Примеры. (доска)

  • {0} — 0-мерное подпространство;
  • для v ∈ V набор {λ v : λ ∈ ℝ} = lin{v} — 1-мерное (если v ≠ 0);
  • само V — подпространство.

Не-пример. Открытый луч {λ v : λ > 0} не подпространство: нет нуля и нет отрицательных растяжений.

Линейная оболочка lin / span

Определение. (из записей) Для v₁, …, vₖ ∈ V

Формула
lin{v₁,…,vₖ} := span{v₁,…,vₖ} := ⟨v₁,…,vₖ⟩
:= { ∑ λᵢ vᵢ : λᵢ ∈ K }

Для произвольного U ⊂ V: lin U — все конечные линейные комбинации элементов U.

Своими словами. Самое маленькое линейное подпространство, содержащее данные векторы: «натянули» на них все комбинации.

Предложение. (из записей / стандартно) dim lin U = r тогда и только тогда, когда в U есть ЛНЗ набор из r векторов, порождающий lin U (т.е. базис оболочки длины r).

Пример. lin{(1,0), (2,0), (0,1)} = ℝ², dim = 2 (первые два ЛЗ; базис оболочки — например (1,0) и (0,1)).

Аффинные подпространства

Определение. (из записей) Аффинное подпространство — сдвиг линейного:

Формула
A′ = X + lin U := { Y : XY ∈ lin U }

Размерность: dim A′ := dim(lin U) (на доске также dim(X + lin U) = r при dim lin U = r).

Своими словами. Берёшь линейное подпространство направлений и «приклеиваешь» его к точке X. Прямая, плоскость, точка — всё это сдвиги {0}, прямой через 0, плоскости через 0.

Примеры.

  • Точка: {X} = X + {0}, dim = 0.
  • Прямая: при n ≥ 1 точка X и ненулевой u: { Y : XY = λ u } — аффинная прямая, dim 1.
  • Плоскость: при n ≥ 2 точка X и неколлинеарные u, v: A² = { Y : XY = λ u + μ v } — аффинная плоскость, dim 2. (Рис. L-5c.)
  • Отрезок [XY] — не аффинное подпространство (нельзя выйти за концы комбинациями с произвольными λ), но лежит в аффинной прямой aff{X, Y}.

Аффинная оболочка aff

Определение. aff B — наименьшее аффинное подпространство, содержащее множество точек B (аффинная оболочка). Для конечного набора:

aff{X₁, …, Xᵣ} — все аффинные комбинации ∑ λᵢ Xᵢ с ∑ λᵢ = 1.

Предложение. (из записей)

  1. dim aff{X₁, …, Xᵣ} ≤ r − 1;
  2. dim aff{X₁, …, Xᵣ} = r − 1 ⟺ существует O ∈ A такое, что dim lin{OX₁, …, OXᵣ} = r − 1 (эквивалентно: векторы OX₁, …, OXᵣ «почти» ЛНЗ — оболочка размерности r−1; геометрически точки «в общем положении»).

Своими словами. r точек порождают аффинное пространство размерности не выше r−1 (две точки — прямая dim ≤ 1, три — плоскость dim ≤ 2). Равенство — когда точки не «сплющены» в меньшую размерность.

Пример. Три точки не на одной прямой: dim aff = 2 (плоскость треугольника). Три точки на прямой: dim aff = 1 < 3−1.

Не-пример равенства. Четыре вершины параллелограмма: r−1 = 3, но все лежат в одной плоскости ⇒ dim aff = 2 < 3.

Что взять с собой

  • Центр масс = аффинная комбинация с весами mᵢ/M; рычаг XZ/ZY = m₂/m₁.
  • В треугольнике 7 областей знаков барицентрических координат.
  • Сужение F|_{A′}^{B′} — та же F на меньших множествах (образ ⊂ B′).
  • Линейное подпространство ⇔ u+λv ∈ U; lin = span.
  • Аффинное: A′ = X + lin U; dim A′ = dim lin U.
  • dim aff{X₁..Xᵣ} ≤ r−1; равенство — точки в общем положении.

Связь с прошлым. До сих пор в векторном пространстве V умели только складывать и растягивать векторы — длин и углов там не было (аффинная геометрия L2–L5 их не знает). §5 добавляет к V новую операцию — скалярное произведение; из неё появятся длина (норма), угол, проекция, расстояние.

Скалярное произведение: определение

Определение. (из записей) Пусть V — векторное пространство над ℝ. Скалярным произведением на V называется отображение

Формула
V × V → ℝ, (u, v) ↦ ⟨u, v⟩ = u·v

со свойствами (аксиомами):

  1. ∀ v ∈ V: v·v ≥ 0 — положительная определённость;
  2. ∀ v ∈ V: v·v = 0 ⟺ v = 0 — невырожденность;
  3. ∀ u, v ∈ V: u·v = v·u — симметричность;
  4. ∀ u, v, w ∈ V, ∀ λ ∈ ℝ: (u + λv)·w = u·w + λ(v·w) — линейность по первому аргументу.

Своими словами. Это правило, которое двум векторам ставит в соответствие число (не вектор!). Аксиомы 1–2: «вектор, умноженный сам на себя, даёт квадрат длины» — он неотрицателен и равен нулю только у нулевого вектора. Аксиома 3: порядок множителей не важен. Аксиома 4: по первому месту можно «раскрывать скобки» и выносить числа, как в школе.

Пример. В ℝ² для u = (x₁, y₁), v = (x₂, y₂) положим u·v = x₁x₂ + y₁y₂ (школьная формула в координатах). Проверка: v·v = x₂² + y₂² ≥ 0 (акс. 1); = 0 только при x₂ = y₂ = 0 (акс. 2); x₁x₂ + y₁y₂ = x₂x₁ + y₂y₁ (акс. 3); акс. 4 — раскрытие скобок. Числа: (1, 2)·(3, −1) = 3 − 2 = 1.

Не-пример 1. u·v = x₁x₂ − y₁y₂: для v = (0, 1) получаем v·v = −1 < 0 — нарушена аксиома 1.

Не-пример 2. u·v = x₁x₂ (вторую координату забыли): v = (0, 1) ≠ 0, но v·v = 0 — нарушена аксиома 2 (невырожденность).

Линейность по второму аргументу (на лекции — упражнение «следует из 3 и 4»; разобрано — дополнено):

u·(v + λw) = (v + λw)·u [акс. 3] = v·u + λ(w·u) [акс. 4] = u·v + λ(u·w) [акс. 3 дважды].

Своими словами. Симметричность позволяет «перенести» линейность с первого места на второе. Итог: скалярное произведение линейно по каждому аргументу (билинейно).

Полезное следствие. 0·v = 0 для любого v: (0 + 1·0)·v = 0·v + 0·v, то есть 0·v = 2(0·v), откуда 0·v = 0.

Неравенство Коши–Буняковского(–Шварца)

Предложение. (из записей)

Формула
∀ u, v ∈ V: (u·v)² ≤ (u·u)(v·v) (кратко u² v²)

Своими словами. Скалярное произведение двух векторов по модулю не больше произведения их «длин». В школе это видно из u·v = |u||v| cos α и |cos α| ≤ 1; но здесь косинуса ещё нет — неравенство доказывается из одних аксиом, и потом именно оно позволит определить угол (L7).

Доказательство. (из записей; шаги расписаны — дополнено)

Шаг 0. Если v = 0, то u·v = 0 и v·v = 0 — обе части нули, неравенство верно. Дальше v ≠ 0, значит v·v > 0.

Шаг 1. Для любого числа λ вектор u + λv умножим сам на себя. По аксиоме 1 результат ≥ 0:

(u + λv)·(u + λv) ≥ 0.

Шаг 2. Раскроем скобки по линейности (по обоим аргументам) и симметричности:

(u + λv)·(u + λv) = u·u + 2λ(u·v) + λ²(v·v).

Шаг 3. Это квадратный трёхчлен по λ: f(λ) = aλ² + bλ + c, где a = v·v > 0, b = 2(u·v), c = u·u. Он неотрицателен при всех λ, т.е. у параболы ветви вверх и она не опускается ниже оси. Значит у трёхчлена не больше одного корня, и дискриминант ≤ 0:

b² − 4ac = 4(u·v)² − 4(u·u)(v·v) ≤ 0.

Шаг 4. Делим на 4: (u·v)² ≤ (u·u)(v·v). ∎ (Рис. L-6a.)

Когда равенство (дополнено; на 26.10 это всплывёт у проекции). Равенство ⟺ D = 0 ⟺ у f есть корень λ₀ ⟺ (u + λ₀v)·(u + λ₀v) = 0 ⟺ (акс. 2) u + λ₀v = 0 ⟺ u = −λ₀v, то есть u и v коллинеарны.

Пример. u = (1, 2), v = (3, 1) в ℝ² со стандартным произведением: u·v = 3 + 2 = 5, u·u = 5, v·v = 10. Проверка: 5² = 25 ≤ 5·10 = 50 ✓ (строго — векторы не коллинеарны).

Пример равенства. u = (1, 2), v = (2, 4) = 2u: u·v = 10, u·u = 5, v·v = 20, и 10² = 100 = 5·20 — равенство, как и предсказано для коллинеарных.

Норма вектора

Определение. (из записей) Пусть V — векторное пространство. Нормой на V называется отображение V → ℝ_{≥0}, v ↦ ‖v‖ («норма вектора v»), такое что

  1. ∀ v ∈ V: ‖v‖ = 0 ⟺ v = 0;
  2. ∀ v ∈ V, ∀ λ ∈ ℝ: ‖λv‖ = |λ|·‖v‖;
  3. ∀ u, v ∈ V: ‖u + v‖ ≤ ‖u‖ + ‖v‖ — неравенство треугольника.

(В записи в п. 3 стоит |u+v| — имеется в виду ‖u+v‖.)

Своими словами. Норма — абстрактная «длина»: неотрицательна, ноль только у нулевого вектора; растянул вектор в λ раз — длина умножилась на |λ| (знак не важен: развернуть стрелку — длина та же); «обходной путь» из двух сторон треугольника не короче прямого.

Пример. В ℝ²: ‖(x, y)‖ = √(x² + y²) — обычная длина. ‖(3, 4)‖ = 5; ‖−2·(3, 4)‖ = ‖(−6, −8)‖ = 10 = |−2|·5 ✓.

Пример (другие нормы на том же ℝ²) (дополнено): ‖(x, y)‖₁ = |x| + |y| («манхэттенская») и ‖(x, y)‖_∞ = max(|x|, |y|). Для (3, 4): ‖·‖₁ = 7, ‖·‖_∞ = 4. Все три аксиомы выполнены — это тоже нормы, просто «длина» меряется по-другому. На одном пространстве норм много.

Не-пример. ‖(x, y)‖ = |x|: для v = (0, 1) ≠ 0 получаем ‖v‖ = 0 — нарушена аксиома 1.

Пример: Eⁿ (на доске — E³)

(из записей) В обычном пространстве возьмём орты i, j, k (попарно перпендикулярные векторы длины 1, оси x, y, z). Для

v = αi + βj + γk, w = δi + εj + ζk:

Формула
‖v‖ = √(α² + β² + γ²)
v·w = αδ + βε + γζ
v·v = ‖v‖²

Своими словами. В координатах относительно ортов скалярное произведение — «перемножь соответствующие координаты и сложи», а норма — теорема Пифагора. И они связаны: v·v = α² + β² + γ² = ‖v‖².

Пример. v = (1, 2, 2), w = (2, 0, 1): v·w = 2 + 0 + 2 = 4; ‖v‖ = √(1+4+4) = 3, v·v = 9 = 3² ✓.

Норма, согласованная со скалярным произведением

Определение. (из записей) Скалярное произведение «·» согласовано с нормой ‖·‖, если

Формула
∀ u ∈ V: u·u = ‖u‖², т.е. ‖u‖ = √(u·u)

Своими словами. Длина берётся «из» скалярного произведения: умножь вектор на себя и извлеки корень. Пример Eⁿ выше — ровно такой случай.

Утверждение. (из записей: «это норма всегда (упр)»; разбор — дополнено) Для любого скалярного произведения формула ‖u‖ := √(u·u) задаёт норму.

Проверяем три аксиомы нормы:

  1. ‖u‖ = 0 ⟺ u·u = 0 ⟺ u = 0 — это аксиома 2 скалярного произведения. (Корень определён: u·u ≥ 0 по аксиоме 1.)
  2. ‖λu‖ = √((λu)·(λu)) = √(λ²(u·u)) = |λ|·√(u·u) = |λ|·‖u‖ — вынесли λ из обоих аргументов, √(λ²) = |λ|.
  3. Неравенство треугольника — через КБШ. В норменных обозначениях КБШ: |u·v| ≤ ‖u‖·‖v‖. Тогда
    ‖u + v‖² = (u+v)·(u+v) = ‖u‖² + 2(u·v) + ‖v‖² ≤ ‖u‖² + 2‖u‖‖v‖ + ‖v‖² = (‖u‖ + ‖v‖)².
    Обе части неотрицательны — извлекаем корень: ‖u + v‖ ≤ ‖u‖ + ‖v‖. ∎

Своими словами. Неравенство треугольника для «длины из скалярного произведения» — это КБШ в другой одежде.

Пример. u = (3, 0), v = (0, 4): ‖u + v‖ = ‖(3, 4)‖ = 5 ≤ 3 + 4 = 7 ✓.

Теорема: какая норма приходит из скалярного произведения (формулировка)

(из записей; на 19.10 — только формулировка, доказательство — в L7) Пусть дана норма ‖·‖, причём для всех u, v выполнено

Формула
‖u + v‖² + ‖u − v‖² = 2(‖u‖² + ‖v‖²) (тождество параллелограмма)

Тогда существует, и притом единственное, скалярное произведение «·», для которого ‖u‖ = √(u·u). (В записи на с. 48 стоит «‖u‖ ≤ √(u·u)» — по смыслу и по формулировке 26.10 там равенство.)

Своими словами. Не каждая «длина» рождается из скалярного произведения. Проверка — одно тождество: сумма квадратов диагоналей параллелограмма равна сумме квадратов всех четырёх сторон. Выполнено — скалярное произведение есть (и только одно). Подробно и с примерами — L7.

Что взять с собой

  • Скалярное произведение: V×V → ℝ; v·v ≥ 0; v·v = 0 ⟺ v = 0; u·v = v·u; линейно по 1-му (а значит и по 2-му) аргументу.
  • КБШ: (u·v)² ≤ (u·u)(v·v). Доказательство: (u+λv)·(u+λv) ≥ 0 при всех λ ⇒ D ≤ 0. Равенство ⟺ u, v коллинеарны.
  • Норма: ‖v‖ = 0 ⟺ v = 0; ‖λv‖ = |λ|‖v‖; ‖u+v‖ ≤ ‖u‖+‖v‖.
  • √(u·u) — всегда норма (треугольник — из КБШ). В E³: v·w = αδ+βε+γζ, ‖v‖ = √(α²+β²+γ²).
  • Норма из скалярного ⟺ тождество параллелограмма (доказательство — L7).

Теорема о тождестве параллелограмма

Теорема. (из записей) Пусть ‖·‖ — норма на V. Следующие условия равносильны (С.У.Р.):

  1. ∀ u, v: ‖u + v‖² + ‖u − v‖² = 2(‖u‖² + ‖v‖²);
  2. существует скалярное произведение «·» такое, что ∀ u ∈ V: ‖u‖ = √(u·u).

(В записи в п. 1 второе слагаемое — ‖u+v‖²; по формулировке 19.10 и по доказательству — ‖u − v‖².)

Своими словами. u + v и u − v — две диагонали параллелограмма, натянутого на u и v. Тождество: «сумма квадратов диагоналей = сумма квадратов четырёх сторон» (две стороны длины ‖u‖, две — ‖v‖). В школе это теорема про параллелограмм; оказывается, именно это свойство отличает «евклидовы» длины от всех прочих норм. (Рис. L-7a.)

Пример. ℝ², обычная длина, u = (1, 0), v = (0, 1): ‖u+v‖² + ‖u−v‖² = 2 + 2 = 4 = 2(1 + 1) ✓ — норма из скалярного произведения (стандартного).

Не-пример. Норма ‖(x, y)‖₁ = |x| + |y| (из L6), те же u, v: ‖u+v‖₁ = ‖(1,1)‖₁ = 2, ‖u−v‖₁ = ‖(1,−1)‖₁ = 2. Слева 4 + 4 = 8, справа 2(1 + 1) = 4. Тождество нарушено ⇒ никакое скалярное произведение не даёт норму ‖·‖₁. (Так же «ломается» ‖·‖_∞.)

Доказательство 2 ⇒ 1 (и формулы поляризации)

(из записей) Пусть ‖u‖² = u·u. Раскрываем скобки по линейности и симметричности:

‖u + v‖² = (u+v)·(u+v) = ‖u‖² + 2(u·v) + ‖v‖²,

‖u − v‖² = (u−v)·(u−v) = ‖u‖² − 2(u·v) + ‖v‖².

Складываем: 2(u·v) и −2(u·v) сокращаются, остаётся 2‖u‖² + 2‖v‖² — это и есть (1). ∎

Попутно из каждой строки выражается само скалярное произведение через норму — формулы поляризации:

Формула
u·v = (‖u + v‖² − ‖u‖² − ‖v‖²) / 2 = (‖u‖² + ‖v‖² − ‖u − v‖²) / 2

Своими словами. Если длины известны, скалярное произведение уже ничем не «свободно» — оно вычисляется по длинам. Отсюда единственность в теореме (L6): два разных скалярных произведения с одной нормой дали бы одинаковые правые части.

Пример. u = (1, 2), v = (3, 1): ‖u+v‖² = ‖(4,3)‖² = 25, ‖u‖² = 5, ‖v‖² = 10. (25 − 5 − 10)/2 = 5 = 1·3 + 2·1 ✓.

Доказательство 1 ⇒ 2

(из записей) Пусть норма удовлетворяет тождеству параллелограмма. Подсказка из 2 ⇒ 1: если скалярное произведение есть, то оно обязано быть поляризацией. Поэтому определяем

Формула
u·v := (‖u + v‖² − ‖u‖² − ‖v‖²) / 2

и проверяем, что это скалярное произведение (четыре аксиомы L6) и что u·u = ‖u‖².

Аксиомы 1–2 и согласованность. u·u = (‖2u‖² − ‖u‖² − ‖u‖²)/2 = (4‖u‖² − 2‖u‖²)/2 = ‖u‖² (использовали ‖2u‖ = 2‖u‖ — аксиома нормы 2). (В записи «= ‖u‖ ≥ 0» — должно быть ‖u‖².) Значит u·u ≥ 0, u·u = 0 ⟺ ‖u‖ = 0 ⟺ u = 0, и √(u·u) = ‖u‖.

Аксиома 3. u·v = v·u — формула симметрична: ‖u+v‖ = ‖v+u‖.

Аксиома 4 (линейность по первому аргументу) — главная работа. Нужно (u + λv)·w = u·w + λ(v·w). Разобьём на аддитивность (u+v)·w = u·w + v·w и однородность (λu)·w = λ(u·w); вместе они и дают аксиому 4.

Шаг 1. Частный случай: (2u)·w = 2(u·w). По определению

(2u)·w = (‖2u + w‖² − 4‖u‖² − ‖w‖²)/2.

Чтобы избавиться от ‖2u + w‖, применим тождество параллелограмма к векторам «u» := u + w и «v» := u (их сумма 2u + w, разность w):

‖2u + w‖² + ‖w‖² = 2‖u + w‖² + 2‖u‖² ⇒ ‖2u + w‖² = 2‖u + w‖² + 2‖u‖² − ‖w‖².

Подставляем:

(2u)·w = (2‖u + w‖² + 2‖u‖² − ‖w‖² − 4‖u‖² − ‖w‖²)/2 = 2·(‖u + w‖² − ‖u‖² − ‖w‖²)/2 = 2(u·w). ✓

По симметричности то же и во втором аргументе: u·(2w) = 2(u·w).

Шаг 2. Аддитивность: (u + v)·w = u·w + v·w. Удобнее доказать вдвое большее равенство. По шагу 1:

2((u+v)·w) = (u+v)·(2w) = (‖u + v + 2w‖² − ‖u + v‖² − 4‖w‖²)/2.

Тождество параллелограмма для «u» := u + w и «v» := v + w (сумма u + v + 2w, разность u − v):

‖u + v + 2w‖² = 2‖u + w‖² + 2‖v + w‖² − ‖u − v‖².

Подставляем, а пару −‖u+v‖² − ‖u−v‖² заменяем по тождеству параллелограмма для u, v на −2‖u‖² − 2‖v‖²:

2((u+v)·w) = (2‖u + w‖² + 2‖v + w‖² − 2‖u‖² − 2‖v‖² − 4‖w‖²)/2

= 2·[(‖u + w‖² − ‖u‖² − ‖w‖²)/2 + (‖v + w‖² − ‖v‖² − ‖w‖²)/2] = 2(u·w + v·w).

Делим на 2. ✓ (Здесь −4‖w‖² разложили как −2‖w‖² − 2‖w‖² — по одному на каждую скобку.)

Шаг 3. Натуральные множители: (nu)·v = n(u·v), n ∈ ℕ. Индукция по n с помощью аддитивности. База n = 1 очевидна. Переход:

(nu)·v = (u + (n−1)u)·v = u·v + ((n−1)u)·v = u·v + (n−1)(u·v) = n(u·v).

Шаг 4. Целые множители (на лекции — упражнение «(−u)·v = −(u·v)»; разобрано — дополнено). Сначала 0·v = (‖v‖² − 0 − ‖v‖²)/2 = 0. Затем по аддитивности

0 = (u + (−u))·v = u·v + (−u)·v ⇒ (−u)·v = −(u·v).

Вместе с шагом 3: ((−n)u)·v = −((nu)·v) = −n(u·v). Итого (nu)·v = n(u·v) для всех n ∈ ℤ.

Шаг 5. Рациональные множители. Пусть q = n/m, n ∈ ℤ, m ∈ ℕ. По шагу 3 (множитель m) и шагу 4 (множитель n):

m·((qu)·v) = (m·qu)·v = (nu)·v = n(u·v) = m·(n/m)(u·v) = m·q(u·v).

Делим на m: (qu)·v = q(u·v) для всех q ∈ ℚ.

Шаг 6. Вещественные множители — через непрерывность. Остался λ ∈ ℝ (например, √2). Идея: приблизить λ рациональными числами и перейти к пределу.

Лемма (обратное неравенство треугольника). (из записей, на полях) | ‖u‖ − ‖v‖ | ≤ ‖u − v‖. Доказательство: ‖u‖ = ‖(u − v) + v‖ ≤ ‖u − v‖ + ‖v‖, т.е. ‖u‖ − ‖v‖ ≤ ‖u − v‖; поменяв u и v местами (‖v − u‖ = ‖u − v‖), получим и ‖v‖ − ‖u‖ ≤ ‖u − v‖.

Непрерывность. Напоминание (матан): f непрерывна в t₀, если ∀ε > 0 ∃δ > 0: |t − t₀| < δ ⇒ |f(t) − f(t₀)| < ε. Функция t ↦ ‖tu + v‖ непрерывна: по лемме

| ‖tu + v‖ − ‖t₀u + v‖ | ≤ ‖(t − t₀)u‖ = |t − t₀|·‖u‖,

и при u ≠ 0 достаточно взять δ := ε/‖u‖. (На доске то же показано для ‖tu‖: | |t|‖u‖ − |t₀|‖u‖ | ≤ ‖u‖|t − t₀| < ‖u‖δ = ε при δ = ε/‖u‖.) Тогда и

f(t) := (tu)·v = (‖tu + v‖² − t²‖u‖² − ‖v‖²)/2

непрерывна по t: сумма и произведение непрерывных функций.

Предельный переход. Возьмём рациональные λₙ → λ. По шагу 5 (λₙu)·v = λₙ(u·v) → λ(u·v). С другой стороны, по непрерывности f (определение по Гейне: xₙ → x₀ ⇒ f(xₙ) → f(x₀)) (λₙu)·v = f(λₙ) → f(λ) = (λu)·v. Предел один, значит (λu)·v = λ(u·v). ✓

Итог. Аддитивность (шаг 2) + однородность (шаг 6) дают (u + λv)·w = u·w + (λv)·w = u·w + λ(v·w) — аксиома 4. Все аксиомы проверены, теорема доказана. ∎

Своими словами (весь план). Определили «кандидата» поляризацией; аксиомы 1–3 бесплатны; для линейности: тождество параллелограмма даёт удвоение и сумму → дальше по цепочке ℕ → ℤ → ℚ, а до ℝ дотягиваемся непрерывностью нормы. Тот же «лестничный» приём, что у аддитивных функций в L3: без непрерывности с ℚ на ℝ не перейти.

Пример: Eⁿ и косинус угла

(из записей) В школьной геометрии длина ‖u‖ = √(u·u), а по поляризации и теореме косинусов (треугольник со сторонами u, v, u − v, угол α между u и v):

‖u − v‖² = ‖u‖² + ‖v‖² − 2‖u‖‖v‖ cos α,

Формула
u·v = (‖u‖² + ‖v‖² − ‖u − v‖²)/2 = ‖u‖·‖v‖·cos α

Своими словами. Школьное «произведение длин на косинус» — не отдельное определение, а следствие: аксиоматическое скалярное произведение в E² и E³ совпадает со школьным. (Рис. L-7b.)

Пример. u = (2, 0), v = (1, 1): u·v = 2; ‖u‖ = 2, ‖v‖ = √2; cos α = 2/(2√2) = 1/√2 ⇒ α = 45° — как и видно на клетчатой бумаге.

Угол между векторами

Определение. (из записей) В векторном пространстве со скалярным произведением (неориентированный) угол между ненулевыми векторами u и v задаётся формулой

Формула
∠(u, v) := arccos( u·v / (√(u·u)·√(v·v)) ) ∈ [0, π]

Почему корректно (дополнено). arccos определён только на [−1, 1]. По КБШ |u·v| ≤ √(u·u)·√(v·v), значит дробь как раз в [−1, 1]. Вот зачем КБШ доказывали в L6: без него «угол» был бы не определён.

Своими словами. Угол теперь не рисуют, а вычисляют по скалярному произведению — и это работает в любом пространстве со скалярным произведением, даже в ℝ¹⁰⁰. «Неориентированный» — угол от u к v и от v к u один и тот же, от 0 до π, без знака.

Пример. В ℝ³: u = (1, 2, 2), v = (2, 0, 1): u·v = 4, ‖u‖ = 3, ‖v‖ = √5, ∠(u, v) = arccos(4/(3√5)) ≈ arccos 0,596 ≈ 53,4°.

Пример (прямой угол). u = (1, 1), v = (1, −1): u·v = 0 ⇒ ∠ = arccos 0 = π/2.

Не-пример. Угол с нулевым вектором не определён: в знаменателе √(0·0) = 0.

«Угол» — две идеи, не путать (из записей: «угол (2 идеи) не путать!!!»). (1) Школьный угол-фигура — часть плоскости между двумя лучами из одной точки (заштрихованная область на рисунке в конспекте). (2) Угол между векторами — число из [0, π], вычисляемое формулой выше. Свободным векторам не нужна общая вершина; это число, а не область.

Ортогональная проекция вектора на вектор

Определение (по рисунку на доске). (из записей; формулировка — дополнено) Пусть v ≠ 0. Ортогональная проекция pr_v u — вектор, коллинеарный v, такой что u − pr_v u перпендикулярен v (т.е. (u − pr_v u)·v = 0). Геометрически — «тень» u на прямую вектора v при свете, падающем перпендикулярно. (Рис. L-7c.)

Свойства с доски:

  • u·v = (pr_v u)·v — перпендикулярная составляющая u − pr_v u в произведение с v ничего не вносит;
  • |u·v| = ‖pr_v u‖·‖v‖ — модуль скалярного произведения = длина тени × длина v.

Вывод формулы. (из записей)

Шаг 1. Проекция коллинеарна v: pr_v u = λv для некоторого числа λ. (В записи «= λu» — описка, проекция лежит на прямой v.)

Шаг 2. Умножим на v и воспользуемся первым свойством: (pr_v u)·v = λ(v·v), и (pr_v u)·v = u·v.

Шаг 3. Значит λ = u·v / v·v (делить можно: v ≠ 0 ⇒ v·v > 0).

Формула
pr_v u = (u·v / v·v) · v

Своими словами. Проекция = (число) × v. Число показывает, «сколько раз v укладывается в тень u»: знак плюс — тень по направлению v, минус — против.

Пример. u = (2, 3), v = (1, 1): u·v = 5, v·v = 2 ⇒ pr_v u = (5/2)(1, 1) = (2,5; 2,5). Проверка перпендикулярности: u − pr_v u = (−0,5; 0,5), (−0,5; 0,5)·(1, 1) = 0 ✓. Длина тени ‖pr_v u‖ = 5/√2, и ‖pr_v u‖·‖v‖ = (5/√2)·√2 = 5 = |u·v| ✓.

Пример (тупой угол). u = (−3, 1), v = (1, 0): u·v = −3, v·v = 1 ⇒ pr_v u = (−3, 0) — тень направлена против v.

Равенство в КБШ на языке проекции. (из записей, справа на с. 54) |u·v| = ‖u‖·‖v‖ ⟺ u ∥ v ⟺ ∃ λ, μ (не оба нуля): λu = μv. Через проекцию: ‖pr_v u‖ ≤ ‖u‖ (катет не длиннее гипотенузы), равенство — когда перпендикулярной составляющей нет, т.е. u сам лежит на прямой v.

Расстояние от точки до прямой

Формула. (из записей) Пусть прямая l на плоскости проходит через точку N, n — нормаль к l (ненулевой вектор, перпендикулярный l), M — точка. Тогда

Формула
dist(M, l) = ‖pr_n NM‖ = (|NM·n| / n·n)·‖n‖ = |NM·n| / ‖n‖

Вывод. Расстояние — длина перпендикуляра из M на l. Этот перпендикуляр параллелен n, а его длина равна длине тени вектора NM на направление n (рис. L-7d: синяя «тень» у точки N такой же длины, что и перпендикуляр из M). По формуле проекции ‖pr_n NM‖ = |NM·n / n·n|·‖n‖, а n·n = ‖n‖², поэтому одна ‖n‖ сокращается.

Своими словами. Берёшь любую точку прямой, проводишь вектор в M и смотришь только на его «перпендикулярную к прямой» часть.

Пример. l: 3x + 4y − 5 = 0, M(3, 4). Нормаль n = (3, 4) (коэффициенты при x, y), точка прямой N(−1, 2): 3·(−1) + 4·2 − 5 = 0 ✓. NM = (4, 2), NM·n = 12 + 8 = 20, ‖n‖ = 5 ⇒ dist = 20/5 = 4. Совпадает со школьной формулой |3·3 + 4·4 − 5|/√(3² + 4²) = 20/5 = 4 — она и есть эта формула, записанная в координатах.

Не-пример. Если вместо нормали взять направляющий вектор прямой a = (4, −3): NM·a = 16 − 6 = 10, 10/5 = 2 ≠ 4 — это длина тени вдоль прямой, а не расстояние.

Ортонормированные базисы (начало; продолжение — на следующей паре)

Определение. (из записей: «для некст пары») Базис e₁, …, eₙ пространства со скалярным произведением называется ортонормированным, если

Формула
eᵢ·eⱼ = δᵢⱼ = { 1, i = j; 0, i ≠ j } (в частности eᵢ·eᵢ = ‖eᵢ‖² = 1)

Своими словами. Все векторы базиса единичной длины («нормированы») и попарно перпендикулярны («орто»). δᵢⱼ — символ Кронекера: 1 на «диагонали» i = j, иначе 0. Орты i, j, k из примера E³ (L6) — ортонормированный базис.

Пример. В ℝ²: e₁ = (1, 0), e₂ = (0, 1). Повёрнутый: e₁ = (1/√2)(1, 1), e₂ = (1/√2)(−1, 1): e₁·e₁ = (1+1)/2 = 1, e₂·e₂ = 1, e₁·e₂ = (−1+1)/2 = 0 ✓.

Не-пример. (1, 0), (1, 1) — базис, но (1,0)·(1,1) = 1 ≠ 0 и ‖(1,1)‖ = √2 ≠ 1: не ортонормированный.

Что взять с собой

  • Норма из скалярного ⟺ ‖u+v‖² + ‖u−v‖² = 2(‖u‖² + ‖v‖²). ‖·‖₁, ‖·‖_∞ не проходят (u = (1,0), v = (0,1): 8 ≠ 4).
  • Поляризация: u·v = (‖u+v‖² − ‖u‖² − ‖v‖²)/2 — отсюда единственность.
  • 1 ⇒ 2: удвоение → сумма → ℕ → ℤ → ℚ → ℝ (непрерывность через | ‖u‖ − ‖v‖ | ≤ ‖u − v‖).
  • В Eⁿ: u·v = ‖u‖‖v‖cos α (теорема косинусов).
  • Угол: ∠(u,v) = arccos(u·v / (‖u‖‖v‖)) ∈ [0, π]; корректен благодаря КБШ. Угол-число ≠ угол-фигура.
  • Проекция: pr_v u = (u·v / v·v)·v; u·v = (pr_v u)·v.
  • dist(M, l) = |NM·n| / ‖n‖.
  • ОНБ: eᵢ·eⱼ = δᵢⱼ.
