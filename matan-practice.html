П1 · Индукция, Бернулли, бином

Источник. практика/документ-17-индукция-бином.pdf.
Теория рядом. Сквозная §16.1 (индукция), §17.2 (Бернулли). Бином понадобится в П3 при оценке n/aⁿ.

1.1. Принцип математической индукции

Схема. Есть высказывания P₁, P₂, … Нужно доказать все Pₙ.

  1. База: P₁ верно.
  2. Переход: из Pₙ следует Pₙ₊₁.

Тогда Pₙ верно для всех n ∈ ℕ.

Своими словами. Упала первая костяшка (база), и каждая роняет следующую (переход) — падает весь ряд.

Сильная индукция (вторая форма с листа).
1. P₁ верно.
2. Из P₁, …, Pₙ следует Pₙ₊₁.

Связь с множествами (как на листе). Если A ⊆ ℕ, 1 ∈ A (или наименьший элемент), и n ∈ A ⇒ n+1 ∈ A, то A = ℕ. Это же «домино», только языком множеств.

Пример. Доказать 1 + 2 + … + n = n(n+1)/2.
База n = 1: 1 = 1·2/2.
Переход: сумма до k+1 = k(k+1)/2 + (k+1) = (k+1)(k+2)/2.

1.2. Задача. Неравенство Бернулли

Бернулли
$(1+x)^n\ge 1+nx$ ($x\ge -1,\ n\in\mathbb{N}$)

Условие. Доказать: (1+x)ⁿ ≥ 1 + nx при n ∈ ℕ, x ≥ −1.

Идея (индукция, как в листке).

  1. База n = 1: 1+x ≥ 1+x — верно.
  2. Пусть (1+x)ⁿ ≥ 1 + nx. Умножаем обе части на (1+x) ≥ 0 (здесь нужно x ≥ −1):
    (1+x)ⁿ⁺¹ ≥ (1+nx)(1+x) = 1 + x + nx + nx² = 1 + (n+1)x + nx².
  3. nx² ≥ 0 ⇒ (1+x)ⁿ⁺¹ ≥ 1 + (n+1)x.

Ответ. (1+x)ⁿ ≥ 1 + nx (x ≥ −1, n ∈ ℕ). Что и требовалось.

Не-пример. При x < −1 множитель 1+x отрицательный — при умножении неравенство может перевернуться; условие x ≥ −1 обязательно.

1.3. Биномиальные коэффициенты

Определение. C(n, k) = n! / (k! (n−k)!) — биномиальный коэффициент (число сочетаний).

Пример. C(5, 2) = 120 / (2·6) = 10.

1.4. Задача. Бином Ньютона

Условие. Доказать: (a+b)ⁿ = ∑_{k=0}^{n} C(n,k) aᵏ bⁿ⁻ᵏ.

Идея.

  1. База n = 1: (a+b) = C(1,0)a⁰b¹ + C(1,1)a¹b⁰ = b + a.
  2. Переход: (a+b)ⁿ⁺¹ = (a+b)ⁿ · (a+b) = (∑ C(n,k) aᵏ bⁿ⁻ᵏ)·(a+b).
    Раскрываем в две суммы и перегруппировываем по степеням aᵏ b⁽ⁿ⁺¹⁾⁻ᵏ.
  3. Коэффициент при aᵏ b⁽ⁿ⁺¹⁾⁻ᵏ оказывается C(n, k−1) + C(n, k).
  4. Остаётся тождество Паскаля: C(n, k−1) + C(n, k) = C(n+1, k).

1.5. Тождество Паскаля

Условие. Доказать C(n, k−1) + C(n, k) = C(n+1, k).

Идея (как в листке).

  1. Пишем через факториалы:
    n! / ((k−1)! (n−k+1)!) + n! / (k! (n−k)!).
  2. Выносим n! / ((k−1)! (n−k)!): в скобках остаётся 1/(n−k+1) + 1/k = (k + n − k + 1)/(k(n−k+1)) = (n+1)/(k(n−k+1)).
  3. Получаем (n+1)! / (k! (n+1−k)!) = C(n+1, k).

Ответ. C(n, k−1) + C(n, k) = C(n+1, k).

Своими словами. Соседние числа в строке треугольника Паскаля в сумме дают число под ними в следующей строке — поэтому бином «наследуется» при умножении на (a+b).

П2 · ε–N и простейшие пределы

Источник. Фото доски и тетради в практика/документ-16-29.09.pdf (листы с определениями и 1/n).
Теория рядом. Сквозная: §§9–10 (предел последовательности, свойства), §13 (±∞).

2.1. Последовательность и предел (определения с доски)

Предел ε–N
$\lim x_n=a\iff\forall\varepsilon>0\ \exists N\ \forall n>N:\ |x_n-a|<\varepsilon$

Определение. Последовательность — отображение f: ℕ → ℝ, aₙ = f(n).

Определение (предел). limₙ→∞ aₙ = a означает:

∀ ε > 0 ∃ N ∈ ℕ: ∀ n > N ⇒ |aₙ − a| < ε.

Своими словами. Какую бы узкую «трубку» ширины 2ε вокруг a ни взять, начиная с номера N весь хвост последовательности лежит внутри этой трубки.

Пример. aₙ = 1/n, a = 0. Для ε = 0,1 нужно |1/n| < 0,1 ⇒ n > 10. Подойдёт N = 10: при n > 10 условие выполнено.

2.2. Бесконечные пределы

Определение. aₙ → +∞, если ∀ M > 0 ∃ N: ∀ n > N ⇒ aₙ > M.
aₙ → −∞, если ∀ M > 0 ∃ N: ∀ n > N ⇒ aₙ < −M.
|aₙ| → +∞ (бесконечно большая), если ∀ M > 0 ∃ N: ∀ n > N ⇒ |aₙ| > M.

Своими словами. +∞ — хвост выше любой положительной планки; −∞ — ниже любой отрицательной; «модуль в ∞» — планка по модулю, знак может скакать.

Пример. aₙ = n → +∞; aₙ = −n² → −∞; aₙ = (−1)ⁿ·n — бесконечно большая, но не стремится ни к +∞, ни к −∞.

2.3. Задача. Доказать 1/n → 0

Условие своими словами. Показать по определению, что предел последовательности 1, 1/2, 1/3, … равен 0.

Идея по шагам.

  1. Фиксируем ε > 0. Нужно |1/n − 0| < ε, то есть 1/n < ε ⇒ n > 1/ε.
  2. Берём N = ⌊1/ε⌋ + 1. Тогда N > 1/ε.
  3. Для любого n > N имеем n > 1/ε ⇒ 1/n < ε.

Ответ. lim 1/n = 0; N = ⌊1/ε⌋ + 1 работает для любого ε > 0.

2.4. Задача. 1/n^α → 0 при α ≥ 1

Условие. Показать, что при α ≥ 1 последовательность 1/n^α стремится к 0.

Идея.

  1. При α = 1 это уже разобрано.
  2. При α > 1: 0 ≤ 1/n^α ≤ 1/n (потому что n^α ≥ n).
  3. Крайние члены → 0 ⇒ по теореме о двух милиционерах середина тоже → 0.
  4. Следствие: a/n^α → a·0 = 0 для любой константы a.

Ответ. 1/n^α → 0 (α ≥ 1); a/n^α → 0.

2.5. Задача. (−1)ⁿ не имеет предела

Условие. Показать, что aₙ = (−1)ⁿ не стремится ни к какому конечному a.

Идея (от противного, как на доске).

  1. Предположим aₙ → a. Тогда для малого ε (например ε = 1) хвост должен лежать в (a − 1, a + 1).
  2. В хвосте есть и члены = 1, и члены = −1. Значит |a − 1| < ε и |a + 1| < ε.
  3. Тогда 2 = |1 − (−1)| ≤ |1 − a| + |a − (−1)| < 2ε. При ε ≤ 1 получаем 2 < 2 — противоречие.

Ответ. Предела нет (последовательность «прыгает» между −1 и 1).

П3 · Рациональные дроби и сравнение роста

Источник. практика/документ-16-29.09.pdf — разбор дробей многочленов + доказательства n/aⁿ → 0 и logₙ/n → 0; на доске номера 41–45, 46, 49, 50 (ДЗ).
Ориентир по дате. Ядро сравнения роста — пары около 29.09; дроби многочленов шли раньше в той же цепочке.
Опора на П1. В оценке n/aⁿ используют бином Ньютона (и идею Бернулли).

3.1. Пример. (n² + n + 1)/(2n² + n + 1)

Условие. Найти limₙ→∞ (n² + n + 1)/(2n² + n + 1).

Идея.

  1. Степени числителя и знаменателя одинаковы (= 2). Делим числитель и знаменатель на n²:
    (1 + 1/n + 1/n²) / (2 + 1/n + 1/n²).
  2. 1/n → 0, 1/n² → 0 ⇒ дробь → (1+0+0)/(2+0+0) = 1/2.

Ответ. 1/2.

3.2. Общее правило (степени k и m)

Пусть aₖ ≠ 0, bₘ ≠ 0:

(aₖ nᵏ + … + a₀) / (bₘ nᵐ + … + b₀).

Делим числитель и знаменатель на nᵐ. Тогда:

Сравнение степеней Предел
k < m 0
k = m aₖ / bₘ
k > m ∞ (знак как у aₖ/bₘ)
Правило
k < m → 0;  k = m → aₖ/bₘ;  k > m → ∞ со знаком aₖ/bₘ

Своими словами. Побеждает старшая степень. Если в знаменателе степень больше — дробь «схлопывается» в 0; если равны — остаются старшие коэффициенты; если числитель «длиннее» — уходит в бесконечность.

Пример. (2n⁴ − 3n³ − n² + 2n − 3) = n⁴(2 − 3/n − 1/n² + 2/n³ − 3/n⁴) — вынесли n⁴, в скобках → 2.

Не-пример (ошибка). Делить на nᵏ, если k < m: знаменатель после деления уйдёт в 0, а нужен контроль старшей степени знаменателя — делят на nᵐ.

3.3. Задача. n / aⁿ → 0 при a > 1

Условие. Доказать: при a > 1 последовательность n/aⁿ стремится к 0.

Идея (как на доске; бином — из П1).

  1. Пишем a = 1 + α, α > 0. Нужно n/(1+α)ⁿ → 0.
  2. Бином Ньютона: (1+α)ⁿ = 1 + nα + C(n,2)α² + … ≥ C(n,2)α² = n(n−1)α²/2 (при n ≥ 2).
  3. Тогда 0 < n/(1+α)ⁿ ≤ n / (n(n−1)α²/2) = 2/((n−1)α²).
  4. Правая часть → 0 ⇒ по милиционерам n/aⁿ → 0.

Ответ. lim n/aⁿ = 0 (a > 1).

Своими словами. Экспонента aⁿ растёт быстрее любой линейной n: даже после деления «хвост» прижимается к нулю.

3.4. Задача. (log_a n) / n → 0 при a > 1

Условие. Доказать, что логарифм растёт медленнее любой линейной функции: log_a n / n → 0.

Идея.

  1. Для каждого n найдём целое k = kₙ так, что aᵏ ≤ n < aᵏ⁺¹ (то есть k = ⌊log_a n⌋).
  2. Тогда k ≤ log_a n < k + 1 и n ≥ aᵏ ⇒
    0 < (log_a n)/n ≤ (k+1)/aᵏ.
  3. Из п. 3.3: (k+1)/aᵏ → 0 при k → ∞. А kₙ → ∞ вместе с n (иначе n ограничена степенью a).
  4. Значит (log_a n)/n → 0.

Ответ. lim (log_a n)/n = 0 (a > 1).

3.5. Усиление. (log_a n) / n^α → 0 при α > 0, a > 1

Условие. То же, но в знаменателе любая положительная степень n^α.

Идея. Аналогично: aᵏ ≤ n^α < aᵏ⁺¹ ⇒ k/α ≤ log_a n < (k+1)/α, и (k+1)/aᵏ → 0.

Ответ. lim (log_a n)/n^α = 0.

П4 · Графики сложных функций

Источник. Тетрадные листы в начале практика/документ-16-29.09.pdf (гипербола + композиция с показательной / логарифмом).
Замечание. На первом листе сверху обрывок доказательства Больцано–Вейерштрасса (теория лекции 24.09) — он уже в МТ-§14; здесь только практическая часть с графиками.

4.1. Внутренняя функция y = (x−1)/(x+2)

Условие. Построить график дробно-линейной y = (x−1)/(x+2) (нужна как внутренняя для показательной).

Идея.

  1. Выделяем целую часть: (x−1)/(x+2) = (x+2−3)/(x+2) = 1 − 3/(x+2).
  2. Это сдвиг гиперболы y = −3/x: влево на 2, вверх на 1.
  3. Вертикальная асимптота x = −2; горизонтальная y = 1.
  4. Пересечения: с Ox при x = 1; с Oy при y = −1/2.

Ответ. Гипербола с асимптотами x = −2 и y = 1; ветви в «квадрантах» относительно асимптот.

4.2. Задача. Z = 3^((x−1)/(x+2))

Условие своими словами. Исследовать композицию: сначала дробь y = (x−1)/(x+2), затем Z = 3ʸ. Найти, какие значения принимает Z на (−∞, −2) и на (−2, +∞).

Идея.

  1. Z = 3ʸ, y = (x−1)/(x+2). Показательная всегда > 0.
  2. На (−∞, −2): y пробегает (1, +∞) ⇒ Z = 3ʸ пробегает (3, +∞).
  3. На (−2, +∞): y пробегает (−∞, 1) ⇒ Z пробегает (0, 3).
  4. При x → −2 слева y → +∞ ⇒ Z → +∞; справа y → −∞ ⇒ Z → 0.
    При x → ±∞ y → 1 ⇒ Z → 3 (горизонтальная асимптота Z = 3, не достигается).

Ответ. На (−∞, −2): Z ∈ (3, +∞); на (−2, +∞): Z ∈ (0, 3); асимптота Z = 3 при |x| → ∞; вертикальный «разрыв» при x = −2.

(Уравнение 3^((x−1)/(x+2)) = 2 на том же листе — сводится к (x−1)/(x+2) = log₃ 2 и решается по графику y или алгебраически.)

4.3. Задача. Z = log_{1/2} |x² − x|

Условие. Построить / описать график Z = log_{1/2} |x² − x|.

Идея.

  1. Внутреннее: u = x² − x = x(x−1). Парабола, корни 0 и 1, вершина x = 1/2, u(1/2) = −1/4.
  2. Модуль y = |u|: отрицательная «ямка» отражается вверх → между 0 и 1 получается горб высотой 1/4 в точке x = 1/2; вне [0,1] парабола как была.
  1. Внешнее: Z = log_{1/2} y. Основание < 1 ⇒ логарифм убывает по y. При y → 0⁺ имеем Z → +∞; при y → +∞ имеем Z → −∞.
  2. Вертикальные асимптоты там, где y = 0: x = 0 и x = 1.
  3. В точке x = 1/2: y = 1/4, log_{1/2}(1/4) = 2 — локальный минимум между асимптотами (Z = 2).

Ответ. Асимптоты x = 0, x = 1; между ними «лощина» с минимумом (1/2, 2); слева от 0 и справа от 1 ветви уходят вниз к −∞ при |x| → ∞.

П5 · Предел функции (документ 15)

Источник. практика/документ-15-практика.pdf.
Теория рядом. Сквозная §19 (Коши / Гейне) — определения уже развёрнуты; здесь — выжимка того, что было на практике, плюс свойства.

5.1. Определения (окрестности)

Предельная точка. a ∈ ℝ̄ — предельная точка множества E ⊂ ℝ, если в любой окрестности a есть точка E, отличная от a (эквивалентно: есть последовательность xₙ ∈ E, xₙ ≠ a, xₙ → a).

Стандартные окрестности.
ωₙ(a) = (a − 1/n, a + 1/n);
ωₙ(+∞) = (n, +∞);
ωₙ(−∞) = (−∞, −n).

Определение (общее / «топологическое»). lim_{x→a} f(x) = A (a, A ∈ ℝ̄), если
∀ окрестности G(A) ∃ окрестность ω(a): ∀ x ∈ ω(a) ∩ E, x ≠ a ⇒ f(x) ∈ G(A).

Определение Коши (конечные a, A).
∀ ε > 0 ∃ δ > 0: ∀ x ∈ (a−δ, a+δ) ∩ E, x ≠ a ⇒ |f(x) − A| < ε.

Пример. f(x) = 2x + 1, a = 1, A = 3. |2x+1 − 3| = 2|x−1| < ε при |x−1| < ε/2 — берём δ = ε/2.

5.2. Локальная ограниченность

Утверждение. Если lim_{x→a} f(x) = A ∈ ℝ, то f ограничена в некоторой проколотой окрестности a: ∃ ω̇₀(a), ∃ C > 0: |f(x)| ≤ C на ω̇₀(a) ∩ E.

Идея. Взять ε = 1 ⇒ |f(x) − A| < 1 ⇒ |f(x)| < 1 + |A|. Положить C = 1 + |A|.

5.3. Эквивалентность Коши ⇔ Гейне

Коши ⇔ Гейне
$\varepsilon$–$\delta$  $\Leftrightarrow$  $\forall\{x_n\}\to a,\ x_n\neq a:\ f(x_n)\to A$

Теорема. f(x) → A при x → a ⟺ для любой последовательности xₙ ∈ E, xₙ ≠ a, xₙ → a выполнено f(xₙ) → A.

Коши ⇒ Гейне. Окрестность G(A) даёт окрестность ω(a); хвост xₙ попадает в ω(a) ⇒ f(xₙ) ∈ G(A).

Гейне ⇒ Коши (от противного). Если Коши ложно, есть G₀(A) такая, что в каждой ωₙ(a) найдётся xₙ′ ∈ E ∩ ωₙ(a), xₙ′ ≠ a, с f(xₙ′) ∉ G₀(A). Тогда xₙ′ → a, но f(xₙ′) не → A — противоречие Гейне.

5.4. Единственность предела

Утверждение. Если f(x) → A и f(x) → B при x → a, то A = B.

Идея (через Гейне, как в листке). Берут две последовательности xₙ → a и xₙ′ → a с f(xₙ) → A, f(xₙ′) → B; склеивают t₂ₙ₋₁ = xₙ, t₂ₙ = xₙ′. Тогда tₙ → a ⇒ f(tₙ) имеет предел C; из неравенств треугольника при ε = (1/4)|A−B| получают |A−B| < |A−B| — противоречие, если A ≠ B.

5.5. Арифметика и сравнение

Если f(x) → A, g(x) → B (конечные), то:

  • f + g → A + B;
  • f · g → A · B;
  • если g(x) ≠ 0 и B ≠ 0, то 1/g → 1/B и f/g → A/B.

Если f(x) ≤ g(x) вблизи a (кроме, возможно, самой a) и оба предела конечны, то A ≤ B.

Своими словами. Те же правила, что для последовательностей: предел «проходит» через +, ·, / (где можно) и сохраняет неравенства.

Пример. lim_{x→2} (x² + 1)/(x + 1) = (4+1)/(2+1) = 5/3 — через арифметику, знаменатель → 3 ≠ 0.

П6 · Рекуррентные последовательности (06.10)

Источник. практика/06.10-практика.pdf; фото листа практика/доска-2026-10-06-рекуррентные.jpg.
Теория рядом. Монотонные + Вейерштрасс — МТ-§11; предел и арифметика — МТ-§9–МТ-§10; число $e$ и факториалы пригодятся в ДЗ — МТ-§14.

6.1. Напоминание: монотонная и ограниченная

Схема (как на паре). Если $a_{n+1}\ge a_n$ для всех $n$ и $\{a_n\}$ ограничена сверху, то она сходится, причём

$$\lim a_n = \sup\{a_n\}.$$

Своими словами. Неубывающая «лезет вверх», но не выше крышки $\Rightarrow$ упирается в супремум. Для невозрастающей + ограничена снизу — в инфимум.

Как находим значение предела (как в тетради). (1) индукцией монотонность; (2) индукцией ограниченность; (3) Вейерштрасс — предел существует; (4) обозначаем его буквой $a$, в равенстве $a_{n+1}=f(a_n)$ переходим к пределу: $\lim a_{n+1}=\lim a_n$, значит $a=f(a)$, решаем уравнение и берём подходящий корень (с учётом знака / ограниченности).

6.2. Задача. $a_1=1$, $a_{n+1}=\sqrt{2+a_n}$

Условие. Доказать, что последовательность сходится, и найти предел.

Идея по шагам.

Шаг 1. Первые члены. $a_1=1$, $a_2=\sqrt{3}$, $a_3=\sqrt{2+\sqrt{3}}$. Уже $a_2>a_1$.

Шаг 2. Ограниченность сверху: $a_n<2$. База: $a_1=1<2$. Переход: если $a_n<2$, то
$$a_{n+1}=\sqrt{2+a_n}<\sqrt{2+2}=2.$$

Шаг 3. Монотонность: $a_{n+1}\ge a_n$. База: $a_2=\sqrt{3}>1=a_1$. Переход: из $a_{n+1}\ge a_n$ следует
$$\sqrt{2+a_{n+1}}\ge\sqrt{2+a_n}\iff a_{n+2}\ge a_{n+1}$$
(корень возрастает). На листе ещё через разность (сопряжённое) — это для монотонности, не для значения предела:
$$a_{n+1}-a_n=\sqrt{2+a_n}-a_n=\frac{2+a_n-a_n^2}{\sqrt{2+a_n}+a_n}=\frac{(2-a_n)(1+a_n)}{\sqrt{2+a_n}+a_n};$$
при $0\le a_n<2$ числитель и знаменатель $>0$ $\Rightarrow$ $a_{n+1}>a_n$.

Шаг 4. Сходимость. Неубывает и ограничена сверху $\Rightarrow$ по Вейерштрассу сходится; $\lim a_n=\sup\{a_n\}\le 2$.

Шаг 5. Значение предела (как в тетради). Обозначим предел через $a$ (на листе именно так, не через $L$). Тогда $\lim a_{n+1}=\lim a_n=a$. В рекурсии $a_{n+1}=\sqrt{2+a_n}$ переходим к пределу (корень непрерывен):
$$a=\sqrt{2+a}.$$
Квадрат (обе части $\ge 0$): $a^2=2+a$ $\Rightarrow$ $a^2-a-2=0$ $\Rightarrow$ $(a-2)(a+1)=0$. Корни $a=2$ и $a=-1$. Так как $a_n>0$, берём $a=2$.

Своими словами. Сначала доказали, что предел есть; потом «подставили бесконечность» в рекурсию и получили уравнение на это число.

Ответ. Сходится, $\lim a_n=2$.

Пример (численно). $a_1=1$, $a_2\approx 1{,}73$, $a_3\approx 1{,}93$, $a_4\approx 1{,}98$ — ползёт к 2 снизу.

6.3. Задача. $a_1=0$, $a_{n+1}=\dfrac{a_n+2}{3}$

Условие. Доказать сходимость и найти предел.

Идея по шагам.

Шаг 1. Члены. $a_1=0$, $a_2=2/3$, $a_3=8/9$, … Видно $a_2>a_1$.

Шаг 2. Монотонность. База $a_2>a_1$. Если $a_n>a_{n-1}$, то
$$\frac{a_n+2}{3}>\frac{a_{n-1}+2}{3}\iff a_{n+1}>a_n.$$

Шаг 3. Ограниченность сверху числом 1. База: $a_1=0<1$. Переход: если $a_n<1$, то
$$a_{n+1}=\frac{a_n+2}{3}<\frac{1+2}{3}=1.$$
(Замечание с пары: $x>(x+2)/3$ $\iff$ $x>1$, а $x<(x+2)/3$ $\iff$ $x<1$ — поэтому при старте ниже $1$ последовательность растёт, но не перескакивает через $1$.)

Шаг 4. Сходимость. Неубывает и ограничена сверху $\Rightarrow$ по Вейерштрассу сходится; $\lim a_n\le 1$.

Шаг 5. Значение предела (как в тетради). Обозначим предел через $a$. Тогда $a_n\to a$ и $a_{n+1}\to a$, значит
$$a=\frac{a+2}{3}\implies 3a=a+2\implies a=1.$$

Ответ. Сходится, $\lim a_n=1$.

Пример. $a_4=26/27\approx 0{,}96$ — близко к 1 снизу.

6.4. Задача. $a_1=1$, $a_{n+1}=1+\dfrac{1}{a_n}$

Условие. Исследовать сходимость (на паре — через чётные/нечётные; ДЗ: доделать).

Идея по шагам.

Шаг 1. Члены.
$$a_1=1,\quad a_2=2,\quad a_3=\frac32,\quad a_4=\frac53,\quad a_5=\frac85,\quad a_6=\frac{13}{8}.$$
Нечётные: $1,\ 3/2,\ 8/5,\ldots$; чётные: $2,\ 5/3,\ 13/8,\ldots$. Само по себе $\{a_n\}$ «скачет» — монотонности всей последовательности нет.

Шаг 2. Кандидат (если бы вся последовательность сходилась). Обозначим предел через $a>0$. Из $a_{n+1}=1+1/a_n$ получим $a=1+1/a$ $\Rightarrow$ $a^2-a-1=0$ $\Rightarrow$
$$a=\frac{1+\sqrt{5}}{2}$$
(положительный корень; золотое сечение $\varphi$). На паре это число появляется как кандидат; дальше нужно доказать, что сходимость действительно есть (через чётные/нечётные).

Шаг 3. Рекурсия через один шаг для нечётных.
$$a_{2n+1}=1+\frac{1}{a_{2n}}=1+\frac{1}{1+1/a_{2n-1}}=\frac{2a_{2n-1}+1}{a_{2n-1}+1}=2-\frac{1}{a_{2n-1}+1}.$$
Сравниваем: $a_{2n+1}\ge a_{2n-1}$ (при положительных членах) — база $a_3=3/2>1=a_1$. Значит нечётная подпоследовательность неубывает.

Шаг 4. Чётные убывают. Аналогично из $a_{2n}=1+1/a_{2n-1}$ показывают: чётная невозрастает.

Шаг 5. Ограниченность подпоследовательностей. Нечётные ограничены сверху (например, числом $2$ или $\varphi$), чётные — снизу (например, $\varphi$ или $1$). База $a_1=1<\varphi<a_2=2$; переход: из $\varphi=1+1/\varphi$ и убывания $t\mapsto 1+1/t$ на $(0,+\infty)$ следует, что нечётные $\le\varphi$, чётные $\ge\varphi$.

Шаг 6. Пределы подпоследовательностей. Обе сходятся (Вейерштрасс). Обозначим $\lim a_{2n-1}=A$, $\lim a_{2n}=B$. Из $a_{2n}=1+1/a_{2n-1}$ и $a_{2n+1}=1+1/a_{2n}$:
$$B=1+\frac{1}{A},\qquad A=1+\frac{1}{B}.$$
Тогда $A=B$ и $A=1+1/A$ $\Rightarrow$ $A=B=\varphi$ (положительный корень). Значит вся $\{a_n\}\to\varphi$.

Ответ. Сходится, $\displaystyle\lim a_n=\frac{1+\sqrt{5}}{2}$.

Своими словами. Последовательность «пилит» вокруг $\varphi$: нечётные ползут вверх, чётные — вниз; у обеих подпоследовательностей одно и то же уравнение на предел.

6.5. ДЗ · Есть ли предел

(1) $a_n=\sum_{k=1}^n \dfrac{1}{k(k+1)}$

Идея. Телескоп: $\dfrac{1}{k(k+1)}=\dfrac{1}{k}-\dfrac{1}{k+1}$, значит
$$a_n=\sum_{k=1}^n\Bigl(\frac{1}{k}-\frac{1}{k+1}\Bigr)=1-\frac{1}{n+1}.$$
Ответ. $a_n\to 1$.

(2) $\dfrac{a^n}{a!}$ (как записано на листе)

Условие своими словами. Есть ли предел у последовательности $x_n=\dfrac{a^n}{a!}$ при $n\to\infty$?

Идея. В знаменателе $a!$, а не $n!$. Факториал определён для целых $a\ge 0$, и $a!$ от $n$ не зависит — это просто положительная константа $C=a!$. Значит $x_n=\dfrac{1}{C}\cdot a^n$, и всё решает поведение $a^n$:

  • $a=0$: $x_n=0^n/0!=0$ при $n\ge 1$ $\Rightarrow$ предел $0$;
  • $a=1$: $x_n=1/1!=1$ $\Rightarrow$ предел $1$;
  • $a\ge 2$: $a^n\to+\infty$, делим на постоянную $C>0$ $\Rightarrow$ $x_n\to+\infty$, конечного предела нет.

Пример. $a=3$: $x_n=3^n/6$, то есть $1/2,\ 3/2,\ 9/2,\ 27/2,\ldots$ — растёт без границы.

Ответ. При $a=0$ предел $0$, при $a=1$ предел $1$, при $a\ge 2$ последовательность стремится к $+\infty$ (конечного предела нет).

Дополнено (не с листа). Если на паре имелось в виду стандартное $\dfrac{a^n}{n!}$ (в знаменателе $n!$), то ответ другой — предел $0$ при любом фиксированном $a$. Почему: зафиксируем целое $N>|a|$; для $n>N$
$$\frac{a^n}{n!}=\frac{a^N}{N!}\cdot\frac{a}{N+1}\cdots\frac{a}{n},$$
и каждый множитель после $N$ по модулю не больше $q=|a|/(N+1)<1$, поэтому $\left|\dfrac{a^n}{n!}\right|\le\dfrac{|a|^N}{N!}\,q^{\,n-N}\to 0$. Какой вариант правильный — уточни у преподавателя.

(3) $\dfrac{n!}{n^n}\to 0$

Идея.
$$\frac{n!}{n^n}=\frac{1}{n}\cdot\frac{2}{n}\cdots\frac{n}{n}\le\frac{1}{n}\cdot 1\cdot 1\cdots 1=\frac{1}{n}\to 0.$$
(Более грубо: уже один множитель $1/n$ тянет к нулю, остальные $\le 1$.)

Ответ. Предел $0$.

(4) $\sqrt[n]{a}\to 1$ при $a>1$

Идея. Положим $b_n=\sqrt[n]{a}-1>0$. Тогда $a=(1+b_n)^n\ge 1+n b_n$ (Бернулли) $\Rightarrow$ $0<b_n\le (a-1)/n\to 0$. Значит $\sqrt[n]{a}\to 1$. При $0<a<1$ пишут $\sqrt[n]{a}=1/\sqrt[n]{1/a}$ и сводят к случаю $>1$; при $a=1$ очевидно.

Ответ. Предел $1$ (для $a>0$).

(5) $\sqrt[n]{n}\to 1$

Идея. Аналогично: $n=(1+c_n)^n\ge 1+n(n-1)c_n^2/2$ (бином / Бернулли для квадрата) $\Rightarrow$ $c_n\to 0$. Или: для любого $\varepsilon>0$ при больших $n$ имеем $1<\sqrt[n]{n}<1+\varepsilon$ из сравнения с геометрической (см. также оценку через $n^{1/n}=e^{(\ln n)/n}$ и $(\ln n)/n\to 0$ из МП-П3).

Ответ. Предел $1$.

(6) $a_1=a$, $a_{n+1}=\sqrt{p\,a_n}$ ($p>0$)

Условие. Исследовать сходимость в зависимости от $a>0$, $p>0$.

Идея. Если предел существует и равен $b\ge 0$, то $b=\sqrt{p b}$ $\Rightarrow$ $b=0$ или $b=p$. Явная формула:
$$a_n=p^{1-2^{1-n}}a^{2^{1-n}}$$
(индукция). При $n\to\infty$ показатель у $a$ есть $2^{1-n}\to 0$, у $p$ — $1-2^{1-n}\to 1$, поэтому при $a>0$ имеем $a_n\to p$. (Если $a=0$ — все нули, предел $0$.)

Ответ. При $a>0$ предел равен $p$; при $a=0$ — равен $0$.

(7) $a_1=\dfrac12$, $a_{n+1}=\dfrac{a_n+1}{a_n^2+1}$

Идея. Кандидат: если $a_n\to b$, то $b=(b+1)/(b^2+1)$ $\Rightarrow$ $b(b^2+1)=b+1$ $\Rightarrow$ $b^3=1$ $\Rightarrow$ $b=1$ (вещественный корень). Сходимость: $a_1=1/2$, $a_2=6/5>1$; далее проверить монотонность/ограниченность хвоста или сжатие $|a_{n+1}-1|$ (как в паре — сначала существование, потом уравнение на предел).

Ответ. Сходится, $\lim a_n=1$.

(8) $a_1=2$, $a_{n+1}=\dfrac{a_n^2+2}{2a_n+1}$

Идея.
$$a_{n+1}-1=\frac{(a_n-1)^2}{2a_n+1}\ge 0\quad(a_n>0)\implies a_{n+1}\ge 1;$$
$$a_{n+1}-a_n=\frac{(1-a_n)(2+a_n)}{2a_n+1};$$
при $a_n>1$ имеем $a_{n+1}<a_n$. База $a_1=2>1$. Убывает и ограничена снизу $1$ $\Rightarrow$ сходится. Обозначим предел через $b$: $b=(b^2+2)/(2b+1)$ $\Rightarrow$ $b^2+b-2=0$ $\Rightarrow$ $(b+2)(b-1)=0$; положительный корень $b=1$.

Ответ. Сходится, $\lim a_n=1$.

Что взять с собой

  • Рекуррентная: монотонность + ограниченность $\Rightarrow$ предел существует $\Rightarrow$ в рекурсии переходим к пределу, решаем $a=f(a)$.
  • Если вся $\{a_n\}$ «пилит» — смотри чётные и нечётные (задача с $1+1/a_n$).
  • ДЗ: телескоп, факториалы vs степени, $\sqrt[n]{\,\cdot\,}\to 1$.
